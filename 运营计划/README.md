## 使用顺序

1. 先确认第一篇 7 张图是否完成手机预览。
2. 如果图片没有明显错字，按计划发布第一篇。
3. 每篇发布前跑 `cheat-score -> cheat-predict`。
4. 发布当天登记 `cheat-publish`。
5. 发布后按 T+1 / T+3 / T+7 做观察和复盘。
6. 至少跑完 5 篇完整样本后，再考虑调整 rubric 或内容主线。
