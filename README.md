# OPC 一人公司探索空间

## 项目简介
基于《一人企业方法论》第二版，由 OPC 专家团协作完成的「Agent双路 × 一人公司」自媒体IP建盘全流程。

## 目录结构

├── outputs/                         # OPC 各阶段产出
│   ├── 00-orchestrator/             # 会话摘要
│   ├── 01-resource-audit/           # 资源盘点
│   ├── 02-niche-positioning/        # 利基定位

│   └── 07-conversion-loop/          # 转化闭环 + 内容方案
└── workbuddy/                       # WorkBuddy 协作内容
    ├── AGENTS.md                    # 项目运营规则
    ├── cheat-content/               # cheat-on-content 校准系统

## 核心结论

**定位**：Agent双路——学Agent保饭碗 + 用Agent找退路
> 看到大厂提AI裁员之后，一个普通打工人给自己画了两条路。

**价值主张**：为有产品想法但不会写代码的人，提供用产品思维驾驭AI、将想法直接变成产品的能力路径。

**首篇**：如果明天公司因为AI把你裁了，你手里有什么？
