# OPC 一人公司探索空间

## 项目简介
基于《一人企业方法论》第二版，由 OPC 专家团协作完成的「Vibe Coding × 产品思维」一人公司自媒体IP建盘全流程。

## 目录结构
```
opc-doc/
├── state/           # 进度状态 & 关键决策
├── outputs/         # 各阶段产出
│   ├── 01-resource-audit/      # 资源盘点
│   ├── 02-niche-positioning/   # 利基定位
│   ├── 03-value-proposition/   # 价值主张
│   ├── 04-business-model/      # 商业模式 Lean Canvas
│   ├── 06-mvp-design/          # MVP实验设计
│   ├── 07-conversion-loop/     # 转化闭环（待完成）
│   ├── 08-asset-ops/           # 资产沉淀（运营阶段触发）
│   └── 09-dashboard-review/    # 经营复盘（运营阶段触发）
└── .gitignore
```

## 核心结论

**利基**：Vibe Coding × 产品思维——帮有产品想法的人用AI把想法变成产品，再用AI让产品被看见。

**价值主张**：为有产品想法但不会写代码的人，提供用产品思维驾驭AI、将想法直接变成产品的能力路径——不像技术教程用安装环境劝退新人，也不像纯产品理论只有道理没有产出。
