## 1. 产品目标与定位

**一句话**：这是一个让普通打工人用 12 道情景题，在 1 分多钟内测出自己「准时下班」自由等级（8 档 + 2 隐藏款），并把等级卡「晒」出去、「转给同事对答案」的小红书小工具。

- **解决什么**：把「下班不自由」这个职场人共同的憋屈感，用一个轻量、好玩、有标签感的测试「具象化」——让用户被看见、被共鸣，而不是被说教。
- **给谁用**：普通打工人/牛马（不是产品经理群体），尤其是有「到点想走又不敢走」心理挣扎的上班族。
- **商业/内容目的**：为「Evan下班了」IP 的第 6 篇笔记《用AI准时下班》做互动入口与传播钩子，承接「打工更轻松 → 不浪费时间死磕重复 → 提高时薪 → 想好退路」这条内容母题，把测试流量导回笔记正文与主页。
- **情绪基调**：正面反内卷、给打工人松绑，**不贩卖焦虑**；落点始终是「准时下班/到点下班」。

## 2. 用户画像与使用场景

**核心画像**：25–35 岁一二线城市普通上班族，非管理岗，日常被「到点不敢走」的职场氛围裹挟，内心渴望准时下班、又怕被贴上「不够拼」的标签，情绪憋屈、想找认同、想吐槽。

**典型使用场景（3 个）**：
1. **刷到笔记时**：午休/通勤刷到《用AI准时下班》，点进小工具图个新鲜，1 分钟测完，顺便看看自己啥等级。
2. **下班前的「精神摸鱼」时刻**：还有 20 分钟到点，心已经飞了，点开测一下「我的下班跑路到底啥水平」。
3. **跟同事吐槽加班后**：办公室/群里吐槽完加班，甩一个测试链接「来，测测你是几级牛马」，大家互相对答案、互相调侃。

## 3. 用户故事（含分享动线）

1. **作为普通打工人**，我想用 1 分多钟做完 12 道题，立刻看到一个明确的等级标签（如「Lv8 下班拿捏者」），这样我能快速获得一个「我是谁」的结论和谈资。
2. **作为刚加完班的上班族**，我想看到结果卡的文案「狠狠共情」到我的心声，这样我会觉得这个测试懂我、是嘴替，而不是爹味说教。
3. **作为想晒的人**，我想把带等级徽标的漂亮结果卡「截个图」发到小红书/朋友圈，这样我能用一张图表达我的职场态度，还不尴尬。
4. **作为想拉同事一起玩的人**，我想把结果甩到同事群里对答案，这样互动就自然发生了，测试能被更多人玩到。
5. **作为被低等级结果戳中的人**，我不想被评判、被贩卖焦虑，而是想得到一个正向、可操作的解法引导，这样我不会反感，反而愿意点回笔记继续看。

## 4. 核心玩法与交互流程

### 4.1 完整流程

```
点开小工具（封面）
   ↓
点击「开始测试」（进入答题）
   ↓
逐题作答：12 道情景选择题，每题 A/B/C/D 四选一，点选即下一题
   ↓
第 12 题答完 → 本地计分 → 判定 8 档等级（先判隐藏款）
   ↓
出结果卡（等级徽标 + 有梗称号 + 梗句 + 人设文案 + 钩子文案）
   ↓
单一分享动线：截个图保存 → 转发到同事群对答案（截图已含文案，无需复制文字）
另：结果页展示「上次等级」+「再测一次」（localStorage 记录，纯本地）
```

### 4.2 关键交互细节

- **封面页**：主标题 + Slogan + 一段开场引导 +「开始测试」大按钮 + 隐私声明一行小字。视觉上先抛「12 道题测你的准时下班跑路」+ 等级徽标小预览（制造「我到底会是哪个」的好奇）。
- **答题页**：顶部进度条「第 X / 12 题」；题干用「朋友聊天」口吻写；四个选项为**大卡片按钮**（点击热区 ≥ 44px 高度，适合手机竖屏）；选项**不展示任何等级/分值暗示**，用户凭直觉选。点选后立即进入下一题，减少操作成本。
- **结果页**：结果卡（Canvas 2D 渲染，响应式动态适配画布）占主视觉，卡片结构借鉴 SBTI 结果卡（有梗称号 + 梗句，详见第 12 章），内嵌完整结果文案。卡下方为**单个「截个图保存」引导按钮** +「再测一次」入口 +「上次等级」对比提示。不提供「可选中文本版文案」与「长按复制」动线（截图已含文案，规避剪贴板被禁）。

### 4.3 每个环节如何「激发分享欲」

| 环节 | 分享欲设计 |
|---|---|
| 封面 | 等级徽标预告，制造「我是哪个」的悬念；「12 道题」降低参与门槛 |
| 答题 | 题干戳中真实职场憋屈瞬间（领导 5:58 开会、同事求帮忙、隔壁还在敲键盘、周五下午、deadline、下班后消息），用户内心「这说的就是我」，产生代入感 |
| 出结果 | 等级标签自带「晒点」：高档「拿捏」的爽感、低档「哦不」的自嘲，无论哪档都有可晒/可吐槽的抓手 |
| 结果卡 | 结果卡是**一张「可截图晒」的「会说话的段子」**，视觉精美 + 带账号 IP/机器人，用户晒出去就是帮账号做传播 |
| 分享引导 | 单一动线「截图晒」：文案引导「截个图，转发到同事群对答案」，把「转发」变成一次社交互动（借鉴 SBTI 的「反差自嘲」传播），而非硬广 |

## 5. 需求池（P0 / P1 / P2）

### P0（必须，缺一不可，首版上线）
- **[P0-1] 封面页**：主标题 + Slogan + 开场引导 +「开始测试」按钮 + 隐私声明小字。
- **[P0-2] 12 道情景题**：原 8 题 + 新增 4 题（第 9–12 题，见附录 A），每题 A/B/C/D 四选一，选项位置打散，界面不展示等级暗示；点击热区够大；进度条显示。
- **[P0-3] 本地计分与等级判定**：每题选项分值 S=4 / A=3 / B=2 / C=1（选项位置打散），12 题总分 12–48，纯前端 JS 计算；**先判隐藏款**（满分 48 →「下班跑路的神」、最低 12 →「哦不人·天花板」），再按 8 档区间判定 Lv1–Lv8（详见第 6.3 / 7.3）。
- **[P0-4] 结果卡（Canvas 2D 渲染）**：等级徽标（含配色）+ **有梗称号** + **梗句（第一人称内心 OS）** + 人设文案 + 钩子文案，渲染成一张竖屏可截图「会说话的段子」式卡片；画布按屏宽 + devicePixelRatio 高清渲染，动态适配主流机型竖屏。
- **[P0-5] 结果卡内嵌完整结果文案**：结果文案（含称号/梗句/人设/钩子）以像素/图片形式内嵌于结果卡中，用户通过系统截图保存（规避剪贴板被禁，不提供「可选中文本 + 长按复制」）。
- **[P0-6] 分享引导机制**：结果页单个引导按钮——「截个图保存」，附提示引导转发到同事群对答案（严禁调用剪贴板 / download 等被禁 API）。
- **[P0-7] 隐私声明**：明示「纯本地计算、不采集、不上传任何数据」。
- **[P0-8] 技术合规**：脚本外置、无内联脚本/行内事件、无网络请求、无剪贴板/下载/eval/WebAssembly、无 iframe/Worker、纯本地打包、自包含资源。
- **[P0-9] 竖屏手机适配**：375–430px 主流机型竖屏优先，覆盖安全区（刘海/底部 Home 条）。

### 6.4 字体与圆角等风格基调

- **字体**：首版不打包任何中文字体，统一使用系统字体栈——iOS「PingFang SC」/ Android「HarmonyOS Sans / MiSans」/ 兜底「sans-serif」。复古手写质感由 CSS 实现（字重、字距、描边/投影、斜体与排版节奏等视觉处理），不引入 @font-face 外部字体，避免中文字体子集化的体积与合规成本。
- **结果卡尺寸**：响应式动态适配画布——根据屏幕宽度计算画布逻辑尺寸，并乘以 devicePixelRatio 做高清渲染（保证截图清晰不糊），覆盖主流机型竖屏（含小屏 320px 至大屏/全面屏机型）。卡片内容按比例排版，避免关键文案（等级徽标/称号/梗句）被裁剪。
- **圆角**：卡片 `16px`、按钮 `24px`（大圆角，符合小红书年轻审美）、选项卡片 `14px`。
- **质感**：牛皮纸底 + 撕纸边角 + 半透明胶带色块 + 手绘虚线/墨线描边，营造「剪贴板拼贴」手工感；适度阴影（`0 4px 16px rgba(59,42,28,0.12)`）。
- **布局**：竖屏单列为主，关键按钮大而醒目，避免信息过载。

## 7. 文案体系（重点）

> 语言要求：小红书口吻 + 热梗自然融入，禁用「摸鱼/不卷/下班就跑」，落点统一「准时下班/到点下班」；语气像朋友、有真实感、不爹味、不贩卖焦虑。

### 7.1 小工具标题 / 简介 / Slogan

- **标题**：下班跑路指数
- **简介**：12 道情景题，测测你的「准时下班」自由到底在哪个等级。纯本地计算、不采集数据，放心玩、放心晒。
- **Slogan**：主打一个「准时下班」——8 个等级，你是「下班拿捏者」还是「哦不人」？

### 7.2 开场引导文案

## 12. SBTI 式「会说话的结果标签」传播设计

### 12.1 为什么放弃 MBTI、改借 SBTI

MBTI 是「正向认同」：测出 INFJ / ENTP，用户晒的是「我很高级、我很特别」——卖的是身份优越感。

SBTI 是「反差自嘲」：测出「拿捏者」「妈妈」「哦不人」，用户晒的是「快看我测出了个什么鬼」——卖的是被说中的羞耻 + 反差笑点。那句「哦不！我怎么会是这个人格？！」本身就是传播燃料：截图里不用加任何字，光称号和梗句就够好笑、够想转发。

「下班跑路指数」天然更适合 SBTI 打法，理由有三：
1. 打工人晒「我超会准时下班」容易招仇恨（像炫耀），但晒「我居然是隐形加班奴，哦不！」是自嘲，人人敢转、转完还拉人一起测。
2. 称号的「戏」是现成的：拿捏者 / 候场选手 / 端水大师 / 哦不人，每个名字本身就是一句内心 OS，比四个字母有画面感。
3. 自嘲是打工人社交的硬通货：晒自己惨，比晒自己牛，互动率更高、更安全。

结论：把结果卡做成「SBTI 式」（有梗称号 + 梗句，会说话、像段子）。

### 12.2 结果卡结构（SBTI 式）

一张结果卡，核心只有两样：
- **有梗称号**：会说话、自带戏剧性（如「下班拿捏者」「哦不人·天花板」）。
- **梗句（第一人称内心 OS）**：一句就能当晒点的台词（如「怎么样，准时下班被我拿捏了吧？」「哦不！我怎么会是这个人格？！」）。

称号 + 梗句承担全部晒点，人设文案做「被读懂」的补充，钩子文案做「截个图甩同事群对答案 + 主页承接」。

### 12.3 「反差自嘲」与「不贩卖焦虑」的边界

自嘲是「轻松面对」，不是「贬低 / 吓唬」。三条铁律：
1. 笑点对准「处境」，不对准「人」：可以说「我居然被困在工位」，不说「我很失败、很弱」。
2. 每个自嘲都留「台阶」：Lv1「谁懂啊，我一直觉得晚点走比较安全」后面必须跟「能看见这一点，觉醒就已经开始了」，把自嘲引向「觉醒」，而不是「认命」。
3. 落点永远回收「准时下班」：所有笑料最终都收在「怎么才能到点就走」的正向上，绝不滑向「加班好惨、人生无望」的贩卖焦虑。

一句话：让用户**笑着被说中，而不是苦着脸被戳穿**。

### 12.4 隐藏款设计（借鉴 SBTI「2 特殊结果 + 隐藏分支」）

借鉴 SBTI「2 特殊结果 + 隐藏分支」的盲盒心理，做两个**对称隐藏款**（一个爽到极致、一个自嘲到极致）：

- **隐藏款 1「下班跑路的神」**：12 题全选最高分（满分 48 分）触发。梗句「准时下班不是本事，是本能。怎么样，被神拿捏了吧？」稀有文案「恭喜触发隐藏款！这款可不好测出来。」
- **隐藏款 2「哦不人·天花板」**：12 题全选最低分（12 分）触发。梗句「哦不！我怎么会是这个人格？！原来不是我在上班，是班在上我。」稀有文案「隐藏款 ×2！能把自己测到这份上，也是一种天赋。」

**判定优先级**：先判隐藏款（满分/最低分），再判 8 档（13–47 分）。隐藏款独立配色、独立称号、独立梗句，不走普通档文案模板；分享链路一致（晒图 + 主页承接）。

**重测钩子**（放在每张结果卡底部，普通档也显示）：「听说还有 2 个隐藏款，全选『到点就跑』或全选『待命到底』才能触发——要不要再测一次？」

**实现成本**：纯前端判断——12 题答案集合比对（全最高分 → 隐藏款 1；全最低分 → 隐藏款 2），在结果映射层加一个 if 分支 + 展示层加「隐藏款」角标和稀有文案即可。零后端、零额外成本。

### 12.5 转发引导语（借鉴 SBTI「反差自嘲」的社交货币）
「测测你的「下班跑路指数」是哪一档？截个图发到同事群对答案，看看谁是拿捏者、谁是哦不人。听说还有隐藏款，全选『到点就跑』试试。」

### 12.6 再测对比逻辑（8 档序号）

给每个结果一个可排序的档位序号：哦不人·天花板 = 0 → Lv1 = 1 … Lv8 = 8 → 下班跑路的神 = 9。

**对比规则**：进步/退步 = 本次序号 − 上次序号。

| 差值 | 展示 | 文案口径（不贩卖焦虑） |
|---|---|---|
| N > 0 | ↑N 档 | 「这次比上次多 N 档自由，尊嘟假嘟！离准时下班又近一步」 |
| N = 0 | 持平 | 「还是同一档，主打一个稳定，稳住就是胜利」 |
| N < 0 | ↓N 档 | 「比上次退了 N 档，别慌，班味是会反弹的，下周夺回来」 |

- 主结果大字 = 本次称号 + 本次档色；下方小字 = 「较上次 ↑/↓N 档 / 持平」。
- 退步用中性鼓励口吻，**不责难、不制造焦虑**，落点仍是「把准时下班夺回来」。
- 边界：神(9)→神(9) 显示「稳定封神」；哦不人(0)→哦不人(0) 显示「天花板还在，但今天开始拆天花板」。

### 12.7 落点与母题约束
- 称号/梗句全部锚定「准时下班/到点下班」，情绪正面反内卷、不贩卖焦虑，自嘲不贬低、不吓唬。
- 禁用「摸鱼/不卷/下班就跑」。
- 软承接保留账号母题（打工更轻松 → 不浪费时间死磕重复 → 提高时薪 → 想好退路）+「AI 提效」解法，不承诺跳转。
