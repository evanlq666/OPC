# 小红书小工具平台能力清单与约束（操作指南 PDF 整理）

> 来源：小红书小工具操作指南.pdf（Builder Hub，2 页长图，OCR 提取整理）
> 用途：供产品经理 / 架构师 / 工程师在开发「下班跑路指数」小工具时对照使用

---

## 一、平台定位与入口

- **平台**：小红书 Builder Hub「小工具」，vibecoding 2.0 时代，首批创作者内测。
- **入口**：PC 端「小红书创作者服务中心」https://creator.xiaohongshu.com/ → 左侧菜单「Builder Hub」→「小工具」。
- **挂载方式**：审核通过后，发笔记时在移动端编辑页底部「挂件/组件」入口 →「小工具」分类 → 选择已上传的小工具 → 发布。读者在笔记中点击小工具**直接使用、无需跳出 App**。

## 二、4 步开通流程

1. **STEP 01 找到入口**：登录 PC 端创作者服务中心 → Builder Hub → 小工具。
2. **STEP 02 新建小工具**：填基础信息（名称、简介、图标、Slogan）。
   - 图标格式：png/jpg/jpeg，≤5M，推荐比例 1:1。
3. **STEP 03 上传与配置**：上传产物包（zip），一次上传多次复用，提交审核。
4. **STEP 04 管理**：审核状态、版本更新、上下架，集中管理面板。

## 三、运行环境（核心约束）

- 小工具是运行在**受限沙箱**里的**纯 Web 应用（HTML/CSS/JS）**，当作「能力受限的浏览器页面」开发。
- **技术栈**：标准 HTML/CSS/JS + 标准 Web API，无额外原生桥接接口。
- **沙箱**：部分敏感 Web 能力受限，文件选择、页面跳转统一管控。
- **隔离**：每个小工具独立存储与运行环境，互相隔离，无法访问彼此数据/通信。
- **离线**：**纯本地运行、不联网**。所有页面/脚本/图片/字体必须打包在小工具内，不支持任何网络请求。

## 四、可用能力

| 类别 | 能力 | 说明 |
|---|---|---|
| 渲染 | HTML/CSS/JS | 完整支持（Flexbox/Grid/动画/媒体查询） |
| 渲染 | 内联样式 | `<style>` 与 `style=""` 均可用 |
| 渲染 | 页面内脚本 | 页面自带脚本可正常执行（但见 §五 CSP 约束） |
| 渲染 | Canvas 2D | `getContext('2d')` 完整支持 |
| 渲染 | WebGL | `getContext('webgl'/'webgl2')` 纯渲染可用 |
| 渲染 | 文本选择 | 不限制 |
| 媒体 | 摄像头/麦克风 | getUserMedia，需系统弹窗授权 |
| 媒体 | 选择图片/拍照 | `<input type="file">`，仅支持图片和视频 |
| 媒体 | 音视频播放 | `<video>/<audio>` 内联播放 |
| 存储 | localStorage/sessionStorage | 可用，按小工具独立隔离 |
| 存储 | IndexedDB | 可用，按小工具独立隔离 |
| 存储 | Cookie/Cache API | 可用，按小工具独立隔离（Cookie 仅本地，无登录态鉴权） |
| 交互 | alert()/confirm() | 可用，原生 UI 展示 |

## 五、资源加载规则（CSP 约束，开发硬性）

- **脚本必须外置**：容器**禁止内联 `<script>` 与行内事件处理器（`onclick="..."`）**。JS 写进包内 `.js` 文件用 `<script src="./app.js">` 引入，事件绑定改用 `addEventListener`（不要用 onclick 属性）。
- **样式可内联**：`<style>` 和 `style=""` 都能用，无需外置。
- 图片加载：包内图片、`data: URI`（base64 内嵌）、`blob:`（createObjectURL）均可；**外部域名图片禁止**。
- 字体：`@font-face` 引用包内字体文件；外部域名字体禁止。
- `iframe`/`object`：全部禁止。
- 外部 CDN 一律加载不到，所有资源全部打包进小工具。

**支持的文件类型**：`.html`（必须有且唯一入口）、`.css`、`.js`、`.png/.jpg/.jpeg/.gif/.webp/.svg`、`.woff/.woff2`、`.json`。

## 六、不可用能力（调用会失败，勿用）

### 6.1 已禁用的 Web API
- 定位：`navigator.geolocation`
- **剪贴板：`navigator.clipboard`、`execCommand('copy'/'cut'/'paste')`**
- 硬件：蓝牙、USB、HID、串口
- 传感器：加速度计、陀螺仪、磁力计、环境光、设备运动/朝向
- 实时通信：WebRTC、WebSocket、EventSource(SSE)
- 后台运行：Web Worker、SharedWorker、Service Worker
- 屏幕：屏幕共享、全屏 requestFullscreen（全屏由容器统一管理）
- 设备信息：电池、网络信息、媒体设备枚举
- 存储进阶：持久化存储、跨域存储访问
- 凭据：WebAuthn/credentials、Web Locks
- 窗口：`window.open`、`window.prompt`

### 6.2 已禁用的行为
- **网络请求**：fetch/XMLHttpRequest、加载外部图片/字体/媒体等一切联网请求
- 动态执行代码：`eval()`、`new Function()`、WebAssembly(WASM)
- iframe：页面内嵌 / 被外部嵌入
- 表单跳转提交：`<form>` 提交跳转
- 插件：Flash 等
- **文件下载：`a[download]`、blob 下载等**
- 打开外链/新窗口：`target="_blank"`、跳转站外
- 跳转其他小工具
- 长按菜单（已禁用）

### 6.3 移动端不支持
支付、系统通知/推送、NFC、MIDI、XR/AR/VR、后台同步/下载、PWA 安装、窗口管理、指针/键盘锁定。

## 七、WebGL / 图形计算边界

- 本地资源 / Canvas / 内存对象作纹理：可用。
- 外部域名图片作纹理：不可用（不联网，纹理须打包在内）。
- 依赖 WASM 的加速库（Draco/Basis/ONNX/抠图算法库）：不可用。
- OffscreenCanvas + Worker 离屏渲染：不可用。
- SharedArrayBuffer 多线程：不可用。
- 结论：WebGL 适合用打包资源做本地渲染；AI 图像处理等重计算本期无法支持。

## 八、常见问题 FAQ（摘录）

- 为什么文件只能选图片？→ 出于安全，文件选择仅支持图片和视频。
- 页面里 `<script>` 不执行/报 CSP 错误？→ 禁止内联脚本，JS 外置 + addEventListener。
- 能不能请求自己服务端/加载线上图片？→ 本期不支持任何网络请求，全部打包。
- 需要服务端实时推送？→ 不支持（含 WS/SSE/WebRTC/轮询）。
- 第三方库报错？→ 排查 eval / WASM / Worker / 网络请求，改用允许的等价方案。

## ⚠️ 对本项目的关键影响（开发规格冲突点）

开发规格 §六/§七 中「结果卡可导出为图片（Canvas 或 DOM 截图）、提供保存/分享按钮、复制文案」**与平台能力直接冲突**：

1. **「保存图片到相册」不可用**：`a[download]`、blob 下载被禁用 → 无法程序化保存图片。
2. **「复制文案到剪贴板」不可用**：`navigator.clipboard`、`execCommand('copy')` 被禁用 → 无法一键复制结果文案。
3. **「长按保存图片」也受限**：长按菜单被禁用。

**可行的替代方案（PRD 必须据此设计）**：
- 结果卡**用 Canvas 2D 渲染成一张「可手动截图」的晒图卡**，页面内展示，引导用户**手动截图**分享（截图是系统能力，不受容器限制）。
- 结果文案以**可选中文本**呈现（文本选择「不限制」），引导用户**手动长按选中复制**。
- 「保存/分享」按钮文案必须改为「截个图保存 / 长按复制文案」这类**引导用户用系统能力**的提示，而非调用被禁 API。
