# 第六篇内容规划-小工具

本文件夹用于聚合第六篇内容相关的小红书小工具材料，当前对外名称统一为「下班跑路指数」。

## 文件夹结构

- `01-规划文档/`：第六篇内容方案、PRD、平台能力清单、开发规格、早期修正文档。
- `02-小工具源码/下班跑路指数/`：当前可运行的 HTML/CSS/JS 源码。
- `03-交付包/下班跑路指数.zip`：用于上传小红书小工具平台的最终压缩包。
- `04-预览截图/`：关键页面与修正后的预览截图。
- `05-会话记录/`：本轮沟通、设计取舍和最终产出摘要。

## 当前交付状态

- 小工具名称：下班跑路指数
- 图标格式：PNG
- 图标方向：绿色安全出口风格，小人跑路状态
- 页面结构：首页、答题页、结果页
- 数据策略：纯本地计算，不采集、不上传答题数据
- 最近结果：本地保存最近一次测试结果，可回首页查看
- 结果卡：Canvas 生成，支持保存到相册

## 最终上传包

