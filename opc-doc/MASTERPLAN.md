## 二、核心IP定位

### 一句话
> 看到大厂提AI裁员之后，一个普通打工人给自己画了两条路——一条保饭碗（学Agent），一条找退路（用Agent做副业）。记录每天下班后的真实实验。

### 叙事链
```
刷到裁员新闻 → 开始焦虑 → 问自己"手里有什么"
    → 画出两条路 → 学Agent + 用Agent做副业
    → 每天下班后做实 → 真实记录
    → 自然过渡到Vibe Coding做产品 → 一人公司
```

### 五条内容线
| 线 | 核心问题 | 首5篇占比 |
|----|---------|----------|
| ① AI焦虑 | "我是不是落后了？从哪开始？" | 1篇（首发） |
| ② Agent实践 | "怎么把Agent用进真实工作？" | 3篇 |
| ③ 职场提效 | "怎么少瞎忙？" | 0篇（3-5篇后加入） |
| ④ 个人系统 | "经验和能力怎么沉淀成资产？" | 0篇（5-10篇后加入） |
| ⑤ 一人公司 | "怎么把能力变成长期价值？" | 1篇（第5篇复盘） |

## 三、视觉方案

### 选定风格：暖调水粉（Gouache）
- 哑光质感、大地色系（芥末黄+砖红+灰绿+暖赭+灰蓝）
- 手工笔触、略不完美、温暖踏实
- Evan 半写实手绘角色贯穿所有内容

### 角色设定
| 要素 | 设定 |
|------|------|
| 气质 | 略疲惫但仍在做事，克制、真实 |
| 场景 | 深夜桌边、早班地铁、咖啡店画图、出租屋电脑前 |
| 配色 | 低饱和灰蓝+米白+暗红/橙点缀 |
| 服装 | 普通衬衫/T恤，不刻意 |

### 图文使用规则
```
封面：Evan出现在场景中（地铁刷手机/深夜桌前）
情绪页：Evan处于具体场景（焦虑/犹豫/下笔）
过程页：用桌面、笔记、工具界面承载内容
结果页：展示真实产出或未完成状态
结尾页：Evan继续实验，不摆"已解决"姿态
```
