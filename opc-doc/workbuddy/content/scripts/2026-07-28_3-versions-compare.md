```

· 工作会不会变少
· 经验会不会过期
· 真出事了，我靠什么

焦虑没用，但它会提醒我别装没事
```

### 第3页
```
怕的不是这个

收藏教程：越存越多 / 越看越慌 / 一个也没跑通

先动一下
```

```
我给自己画了两条路
步子不用大

路1·保住工作：拆小任务 → 学Agent → 让工作轻一点
路2·找条退路：找一个问题 → 做个小工具 → 看有没有人需要
```

```
就行了
```

## 版本B：反问版（"你手里有什么"）

### 第1页·封面
```
如果明天因为AI被裁
你手里有什么？

不是问"能不能再找一份工作"
是问你，除了简历那几行字，还有什么
```

### 第2页
```
做了8年产品，我养成一个习惯
遇到不确定的事，先问自己一个问题

我问了自己三遍

第一遍：什么都没有
第二遍：会用一点AI，搭过几个Agent——但只是玩玩
第三遍：打开笔记本，画了两条路
```

### 第3页
```
路1：把Agent变成硬技能
不是"会一点"，是能从零搭出一个能用的Agent
岗位在增长，你先坐上去了，你就是标准

路2：把Agent变成收入来源
做出来→让人知道→让人愿意付费
哪怕一个月几百块，也是你自己赚的

同一套能力，一边安全，一边自由
```

### 第4页
```
这两条路，我同时开始走了

每天下班后记录进展
不是为了写给别人看
是万一哪天被问"你手里有什么"
我不用想三遍
```

### 第5页
```
我每天下班后在做什么

☑ 学Agent——从零搭一个能用的
☑ 跑实验——每周一个，成败都记录
🔄 找退路——用Agent做自己的东西

先让它跑一遍再说
```

### 第6页
```
第一轮肯定不顺
这我知道

结果忽好忽坏 / 提示词写太虚 / 任务选大了
但这些都不是"不行了"的信号
是"再来一次"的信号

卡住了，就改一版
```

### 第7页
```
现在轮到你了

你手里有什么？
写在评论区

关注我，看一个普通人能走多远
```
