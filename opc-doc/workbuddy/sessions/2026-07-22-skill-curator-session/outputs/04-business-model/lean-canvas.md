## 1. Problem（问题）

### Top 3 核心痛点

| 优先级 | 痛点 | 严重度 | 根因分析 |
|--------|------|--------|----------|
| **P1** | **信息过载 → 决策瘫痪** | 🔴🔴🔴🔴🔴 | 12万+ Skill，试一个需安装+配置+测试。绝大多数人装不到10个就放弃探索。P2和P3本质上是P1的衍生问题。 |
| **P2** | **平台评分不可信** | 🔴🔴🔴🔴 | 评分体系不成熟，高分可能是因为描述写得好而非真的好用。用户靠"碰运气"策略随机下载。 |
| **P3** | **场景匹配困难** | 🔴🔴🔴🔴 | 同类Skill几十个（如"设计稿生成代码"类），不知道哪个适合Figma→React、哪个适合截图→HTML。逐个试，大部分试完就删。 |

### 现有替代方案及其缺陷

| 现有方案 | 缺陷 | 用户代价 |
|---------|------|---------|
| 平台排行榜 | 只按下载量/评分排序，无深度评测，可刷榜 | 下载→试→删，每次浪费15-30分钟 |
| AI博主推荐 | "一句话推荐"，无实测、无对比、可能赞助 | 被误导安装了不好用的Skill |
| 社区帖子（即刻/X/小红书） | 碎片化、不成体系、质量极不稳定 | 无法作为可靠决策依据 |
| 自己逐个试 | 时间成本极高，且缺乏多维度判断能力 | 试10个Skill可能花2-3小时 |
| 开发者自荐 | 利益冲突，自卖自夸 | 信息不对称，用户是弱势方 |

## 2. Customer Segments（客户细分）

### 主要客群：AI Agent 深度实操型用户

| 维度 | 描述 |
|------|------|
| **身份标签** | WorkBuddy / Cursor / Copilot 等 AI Agent 工具的深度使用者 |
| **使用深度** | 已安装并使用Agent工具，有主动安装和尝试新Skill的行为，尝过甜头也踩过坑 |
| **痛点视角** | 想用Skill但面对12万+供给不知从何选起，需要一个可信赖的筛选者 |
| **决策角色** | 个人效率主导的自主决策者——自己决定装什么Skill |
| **典型画像** | 产品经理、独立开发者、设计师、技术创业者——跨领域、追求效率、自驱型 |
| **规模估计** | WorkBuddy + Cursor + Copilot 国内DAU合计估计50-100万，其中深度用户（安装过Skill）约10-20万 |

### 次要客群：AI 工具推广者/团队布道者

| 维度 | 描述 |
|------|------|
| **身份标签** | 在团队/社区中负责推荐AI工具的人；技术博主、团队Tech Lead |
| **需求** | 需要一个可信赖的独立来源作为推荐背书 |
| **价值** | 他们本身是传播节点——信任策展人后会把内容转发给更多人 |

### Early Adopters（冷启动期种子用户）

- 即刻/X 上活跃的 AI 工具圈用户
- WorkBuddy/Cursor 重度用户社群成员
- 不满足于平台排行榜、主动寻找独立评测的人

### 排除的客群

| 客群 | 排除原因 |
|------|---------|
| AI 小白/刚接触者 | 需先教育"什么是Skill"，教育成本太高；他们是第二波用户 |
| 企业采购决策者 | 决策链条长，不适合一人公司启动期 |
| Skill 开发者 | 受众太窄，适合第二阶段延伸 |
| 只看不用的信息消费者 | 不会付费，只适合免费层维护 |

## 3. Unique Value Proposition（独特价值主张）

### 一句话UVP

> **「Skill 策展人」—— 每周10分钟，用四维实测（技术×产品×体验×设计）帮你从12万+ AI Skill 中挑出真正值得装的。不只推荐，更教你怎么用。**

### 三层策略

```
        ┌──────────────────────────────────┐
        │    C 底色：降风险型                │
        │  「可信赖的人」— 公开评测标准       │
        │   ┌──────────────────────────┐   │
        │   │  B 壁垒：结果型            │   │
        │   │「拿结果的人」— 付费合集     │   │
        │   │  ┌──────────────────┐   │   │
        │   │  │ A 入口：提效型     │   │   │
        │   │  │「省时间的人」      │   │   │
        │   │  │   免费周刊        │   │   │
        │   │  └──────────────────┘   │   │
        │   └──────────────────────────┘   │
        └──────────────────────────────────┘
```

| 层级 | 定位 | 一句话 | 解决什么 |
|------|------|--------|---------|
| 🅰️ 入口 | 提效型 | "每周10分钟，替代数小时筛选" | P1 信息过载 |
| 🅱️ 壁垒 | 结果型 | "四维实测，不只推荐更教你怎么用" | P2+P3 评分不可信+场景匹配 |
| 🅲️ 底色 | 降风险 | "公开评测标准，信任来自方法论透明" | 长期信任建设 |

### 与竞品的核心差异

| 维度 | 平台排行榜 | AI博主推荐 | 社区帖子 | **Skill策展人** |
|------|-----------|-----------|---------|----------------|
| 筛选深度 | 浅（排序） | 浅（一句话） | 随机 | **深（3000-5000字实测）** |
| 可信度 | 低（可刷） | 中（可能赞助） | 不可控 | **高（方法论透明）** |
| 场景匹配 | 无 | 偶尔 | 偶尔 | **系统化（场景第一维度）** |
| 持续跟踪 | 不跟踪 | 不跟踪 | 不跟踪 | **持续跟踪更新** |
| 同类对比 | 无 | 无 | 偶尔 | **固定对比模块** |

## 4. Solution（解决方案）

### 产品矩阵

| 层级 | 产品 | 形态 | 定价 | Agent自动化 | 节奏 |
|------|------|------|------|------------|------|
| **A 入口** | 免费周刊 | 每周3-5个Skill简评（200-300字/个） | 免费 | 🤖 80% | 第1月起持续 |
| **B 壁垒** | 付费精选合集 | 单个Skill深度评测3000-5000字 | ¥29.9-59.9 | 🤖 60% | 第3-6月上线 |
| **C 信任** | 品牌信任资产 | 公开评测标准+方法论+分类体系 | 免费 | 🤖 50% | 与周刊同步 |

### 各层关键特性

**免费周刊（A入口）:**
- 结构：Skill名称 + 一句话介绍 + 适用场景 + 核心优势 + 1个注意点
- 板块：「本周精选」「生态动向」「已推荐Skill更新追踪」
- 目标：建立"这个策展人靠谱"的第一印象

**付费精选合集（B壁垒）:**
- 六大固定模块：① Skill概述 ② 实测过程（截图+录屏） ③ 场景适配（适合/不适合） ④ 同类对比（2-3个） ⑤ 坑点与注意 ⑥ 综合评分
- 四维评分体系：技术质量 / 产品价值 / 用户体验 / 设计水准
- 目标：用户做决策时只需这一份评测就够了

**品牌信任资产（C底色）:**
- 公开评测维度与权重
- 评测流程透明化（怎么测的、测了什么）
- Skill场景化分类体系（非技术栈分类，而是按用户场景）

### 产品演进路线

```
第1-3月:  免费周刊 + 评测标准公开 → 积累种子用户 + 建立信任
第3-6月:  + 首批付费合集上线 → 验证付费意愿
第6-12月: + 场景化合集（3-5个同类Skill对比）→ 提升客单价
第12月+:  + 自有Skill产品 → 收入结构升级
```

### 渠道矩阵

| 渠道 | 用途 | 内容形态 | 优先级 | Agent自动化 |
|------|------|---------|--------|------------|
| **微信公众号** | 周刊主阵地 + 深度文章 | 图文推送 | 🔴 核心 | 🤖 排版+定时发布 |
| **即刻** | AI工具圈冷启动 + 短评引流 | 短文+话题标签 | 🔴 核心 | 🤖 自动同步短评 |
| **小红书** | 设计/产品圈触达 + 搜索SEO | 图文+场景化标题 | 🟡 辅助 | 🤖 图文自动适配 |
| **邮件Newsletter** | 深度用户留存 + 直达触达 | 周刊全文+独家内容 | 🟡 辅助 | 🤖 全自动发送 |
| **知乎/少数派** | 深度内容SEO + 长尾流量 | 长文评测节选 | 🟢 后期 | 🤖 自动改写分发 |
| **X (Twitter)** | 国际化触达 | 英文短评 | 🟢 后期 | 🤖 翻译+发布 |

### 获客漏斗

```
即刻/X 短评（发现）
    ↓
公众号关注（沉淀）
    ↓
免费周刊订阅（习惯养成）
    ↓
付费合集购买（变现）
    ↓
复购 + 口碑传播（增长飞轮）
```

### 渠道策略说明

- **冷启动期（0-3月）**：即刻为主战场（AI工具圈浓度最高），用短评+话题标签吸引第一批关注
- **增长期（3-9月）**：公众号+Newsletter双轨，公众号做广度，Newsletter做深度
- **成熟期（9月+）**：全渠道分发，Agent自动适配各平台格式

## 6. Revenue Streams（收入来源）

### 收入模型（三阶段）

| 阶段 | 时间 | 收入来源 | 预估月收入 | Agent自动化 |
|------|------|---------|-----------|------------|
| **冷启动** | 0-6月 | 无（纯积累） | ¥0 | — |
| **变现启动** | 3-9月 | 付费合集 | ¥2,000-4,000 | 🤖 支付+交付自动化 |
| **收入放大** | 6-18月 | 合集+自有Skill+会员 | ¥5,000-15,000 | 🤖 全流程自动化 |

### 变现启动期测算

假设条件：
- 周刊订阅 500人
- 付费转化率 5% = 25人
- 均价 ¥39.9/合集
- 月产 2-4个合集

→ 单合集收入 ≈ ¥1,000；月收入 ≈ ¥2,000-4,000

### 定价逻辑

用户买的不是"信息"，而是**"决策时间节省 + 踩坑风险规避"**：

- 一个Skill装错浪费的时间 ≈ 30-60分钟
- 按产品经理时薪¥100计 → 决策风险价值 ¥30-100
- 定价¥29.9-59.9 ≈ 用户试错成本的 1/2 到等值
- 另含"隐性价值"：避坑 × 场景适配 × 长期跟踪

### 未来收入扩展

| 收入类型 | 形态 | 预估定价 | 上线时间 |
|---------|------|---------|---------|
| 场景化合集 | 3-5个同类Skill对比横评 | ¥79.9-99.9 | 第6-12月 |
| 自有Skill产品 | 基于策展洞察开发的Skill | ¥29.9-99.9 | 第12月+ |
| 会员订阅 | 月度精选自动推送+历史合集访问 | ¥19.9/月 | 第12月+ |
| 企业推荐服务 | 团队Skill选型咨询 | ¥500-2000/次 | 第18月+ |

## 9. Unfair Advantage（不公平优势）

### 三层护城河

#### 第一层：创始人能力护城河（即时—12月）

> **四维交叉视角（AI × 产品 × 前端 × 设计）**

这是"学"不出来的能力组合——它是职业路径自然积累的结果：

| 维度 | 在Skill策展中的价值 | 可复制性 |
|------|-------------------|---------|
| AI能力 | 理解Skill技术实现和AI能力边界 | 低（需技术背景） |
| 产品思维 | 从用户场景出发判断Skill的实际价值 | 低（需产品经验） |
| 前端能力 | 评估Skill的技术质量（代码、兼容性） | 低（需开发经验） |
| 设计审美 | 判断Skill产出物的设计水准 | 低（需设计经验） |

四个维度中任一维度单独都不稀缺，但**四个维度的交集**在Skill策展领域几乎没有竞争者。

#### 第二层：先发+数据护城河（6—18月）

- Skill策展领域完全空白，先发窗口12-18个月
- 随着评测积累，形成独有的 **Skill知识图谱**：
  - Skill间的关联与替代关系
  - 场景适配数据（哪个场景适合哪个Skill）
  - 版本变更历史与质量趋势
- 这些数据是"时间的朋友"——越积越厚，后来者无法短期内复制

#### 第三层：Agent工作流护城河（12月+）

- Agent驱动的策展工作流 = 一人公司的产能杠杆
- 60-70%内容生产自动化 → 一人产出接近小团队
- 策展方法论 + Agent编排 = **可规模化的判断力**
- 长期看，策展工作流本身可以产品化（自有Skill/工具）

### 为什么大公司不会做（"看得到、做不了、不想做"）

| 角色 | 为什么不会进入 |
|------|--------------|
| **平台方**（腾讯SkillHub/美团觅游） | KPI是做大货架（Skill数量、下载量），策展是做深精选——价值网络天然冲突。做策展=间接承认平台的Skill不好筛选。 |
| **AI工具公司**（Cursor/Copilot） | 聚焦工具层，内容策展不是核心能力。做了反而显得"偏袒"某些Skill。 |
| **知识付费平台**（得到/极客时间） | 缺乏持续实测能力。Skill策展需要每周安装+测试+对比，不是"请个专家讲一次"的模式。 |
| **AI博主/媒体** | 可以做一两期，但难以持续。因为缺乏四维交叉视角和Agent驱动的工作流，单靠人力无法长期维持深度+频率。 |

## Agent 自动化全景图

### 策展工作流自动化率

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  发现    │ →  │  初筛    │ →  │  实测    │ →  │  评测    │ →  │  发布    │
│  🤖 90%  │    │  🤖 80%  │    │  👤 必须  │    │  🤖 60%  │    │  🤖 90%  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
 自动监控新品      AI打分筛选      人工实机操作      AI生成草稿      自动排版发布
 抓取元数据       top10候选        主观判断        人工终审定调     多渠道分发
```

### 人工不可替代的两个节点

| 节点 | 为什么不能自动化 | Agent辅助方式 |
|------|----------------|--------------|
| **实测** | Skill是否好用、有什么坑、和同类比好在哪——需要人的真实体验和跨领域判断 | Agent辅助安装、运行、截图、记录测试过程 |
| **终审** | 内容的调性、判断的准确度、推荐的可信度——这些决定了策展IP的核心价值 | Agent生成评测草稿，人工审核+润色+定调 |

### 各模块Agent自动化详情

| 模块 | 环节 | Agent负责 | 人工负责 | 自动化率 |
|------|------|----------|---------|----------|
| **发现** | Skill上新监控 | 自动抓取SkillHub/觅游新上架Skill | 设定监控范围和关键词 | 90% |
| **初筛** | 候选打分排序 | AI根据描述+评分+下载量初筛top10 | 确认筛选标准，review初筛结果 | 80% |
| **实测** | 安装运行测试 | 辅助安装、自动截图、记录测试日志 | **实机操作+主观体验判断** | 40% |
| **评测** | 内容撰写 | AI根据实测记录生成评测草稿 | **终审润色+定调+综合评分** | 60% |
| **发布** | 排版分发 | 自动排版、多平台格式适配、定时发布 | 确认发布 | 90% |
| **运营** | 互动回复 | AI生成回复草稿 | 审核+个性化回复 | 70% |
| **跟踪** | Skill更新监控 | 自动检测已推荐Skill的版本更新 | 判断更新是否值得报道 | 85% |
