> 创始人状态：兼职（互联网产品经理），每周约 20 小时

## 一、Pivot 说明

| 项目 | 原始方向 | Pivot 后方向 |
|------|---------|-------------|
| **策展对象** | AI 前端建站提示词 | **AI Skill**（可安装的工具级技能包） |
| **生态基础** | 无成熟平台 | SkillHub（腾讯，8万+）、觅游（美团，4万+）等已有大型分发平台 |
| **策展层** | 国内提示词策展空白 | **Skill 策展完全空白**——平台只做分发，无人在做精选实测 |
| **定价空间** | 9.9 元级别 | 29.9-59.9 元/个 Skill |
| **壁垒** | 选品眼光 | 选品眼光 + Skill 架构判断力 |

### Pivot 逻辑

原始方向"AI 前端建站提示词策展"的核心逻辑依然成立，但发现了一个更好的切法：

1. SkillHub（8万+ Skill）和觅游（4万+ Skill）的存在意味着**供给端已经爆炸**，这正是策展价值最高的时刻
2. 两大平台都是"货架模式"——只做分发，不做精选。策展层完全空白。
3. Skill 是比提示词更高级的资产（可安装的工具包 vs 一次性文本），定价空间和壁垒都更高
4. 创始人的跨领域能力（AI + 产品 + 前端 + 设计）在判断 Skill 质量时更加适用

## 二、三环分析

### 环1：新杠杆 & 元杠杆

#### 新杠杆（无需许可杠杆）

| 杠杆类型 | 在这个赛道的可用性 | 密度评估 |
|---------|------------------|---------|
| **媒体杠杆** | ✅ 极高。周刊、精选集、实测报告、Skill 拆解——所有内容一次生产，无限复用 | ⭐⭐⭐⭐⭐ |
| **代码杠杆** | ✅ 中高。未来可构建 Skill 自动化测试流水线（安装→运行→评分→截图），起步阶段不必须 | ⭐⭐⭐ |

#### 元杠杆（AI 自动化）

| 可自动化环节 | 当前可行性 | 说明 |
|------------|-----------|------|
| Skill 发现与采集 | 高 | AI 可监控 SkillHub/觅游新品上架，自动抓取元数据 |
| Skill 初筛 | 中高 | AI 可根据 Skill 描述/评分/下载量做初步筛选 |
| Skill 实测 | 中 | 需要人工安装测试，但测试过程可模板化 |
| 评测草稿生成 | 高 | AI 可根据测试结果+Skill 结构生成评测初稿 |
| 发布与分发 | 高 | 内容排版→多渠道发布可全自动化 |

**闭环可行性**：`发现→初筛→实测→评测→发布` 整个流程，人工只需在"实测"和"终审"两个节点介入。约 60-70% 环节可自动化。

> ✅ **环1激活**：媒体杠杆极高，AI 自动化策展流水线可行，代码杠杆为后期增量。

### 环2：边界变动

#### 技术边界变动

| 变化 | 影响 |
|------|------|
| **Skill 平台从 0 到 1** | SkillHub（腾讯）和觅游（美团）的出现，标志着"Skill 作为独立商品"的品类成立。两年前这个品类不存在。 |
| **AI Agent 普及** | WorkBuddy、Cursor、Copilot 等 Agent 类工具的普及，让 Skill 的安装和使用门槛大幅降低 |
| **大厂入局** | 腾讯、美团亲自下场做 Skill 平台，意味着这个品类不是昙花一现的玩具 |

#### 信息传播路径变动

| 平台 | 现状 | 机会 |
|------|------|------|
| **即刻** | AI 工具讨论活跃，Skill 相关内容开始出现但不成体系 | 早期内容窗口 |
| **小红书** | AI 效率工具是热门话题，"AI Skill"概念尚未普及 | 教育型内容空间 |
| **微信公众号** | 深度内容适合 Skill 拆解/评测 | 长尾信任积累 |
| **X/Twitter** | 海外 AI 社区活跃，Skill 概念更成熟 | 跨市场信息差套利 |

#### 大公司为什么不追？

| 大公司 | 为什么不追策展层 |
|--------|----------------|
| **腾讯（SkillHub 运营方）** | 核心 KPI 是平台规模（Skill 数量、开发者数、DAU），不是策展质量。自己做策展=既当裁判又当运动员。 |
| **美团（觅游运营方）** | 同上。平台逻辑是"货架要做大"，策展逻辑是"精选要做深"，天然矛盾。 |
| **AI 工具公司（如字节 Trae）** | 聚焦工具层，不会为"策展"配置内容团队 |
| **知识付费平台** | 能做课程，但缺乏持续的 Skill 实测能力（需要技术判断+持续跟踪更新） |

**核心判断**：策展层是典型的"平台看得到、做不了、不想做"的空间——不是能力问题，是价值网络冲突。

> ✅ **环2激活**：平台供给爆炸 + 策展层空白 + 大公司价值网络冲突 = 极佳窗口。

> ✅ **环3激活**：核心竞争力（跨领域质量判断 + 产品思维）恰好是 Skill 策展最稀缺的能力。缺口可补。

## 四、候选利基与六维评分

### 候选 1：🏅「Skill 策展人」— AI Skill 精选策展 IP（主推）

**目标用户**：AI Agent 工具（WorkBuddy/Cursor/Copilot）的深度用户——他们知道 Skill 能大幅提效，但面对 SkillHub 8万+、觅游 4万+ 的 Skill 海洋，不知道哪些真正值得安装。

**核心痛点**：
- 信息过载：12万+ Skill，试错成本极高
- 质量焦虑：平台评分体系不成熟，高分不等于好用
- 场景匹配：不知道"我的工作场景适合哪个 Skill"

**激活的环**：✅环1 ✅环2 ✅环3（三环全激活）

**时间窗口**：现在（2026Q3）是极佳窗口——Skill 平台刚过临界规模（供给端成熟），但策展层尚未出现任何成体系的玩家。窗口宽度约 12-18 个月。

**大公司为什么不追**：平台方（腾讯/美团）的价值网络是"做大货架"，策展是"做深精选"——天然冲突。工具方（字节等）聚焦工具层。知识付费方缺乏持续实测能力。

**六维评分**：

| 维度 | 评分 | 说明 |
|------|------|------|
| 痛点强度 | **5** | 12万+ Skill 的信息过载比提示词更严重，决策成本更高（Skill 需要安装配置） |
| 杠杆密度 | **5** | 媒体杠杆极高 + AI 自动化策展 + 未来代码杠杆（测试工具） |
| 窗口红利 | **5** | 平台刚过临界点，策展层完全空白，先发优势窗口清晰 |
| 资源匹配度 | **5** | 跨领域判断力 + 产品思维 + 提示词工程 = 完美匹配 |
| 交付标准化程度 | **5** | 周刊/精选集天然标准化，Skill 评测模板可复用 |
| 现金流潜力 | **4** | 定价空间 29.9-59.9 元/Skill，路径：免费周刊（3-6月）→ 付费精选合集 → 自有 Skill |

**总分：29/30**

**风险点**：
- 冷启动期零流量（需要前 3 个月坚持输出，建立第一批读者）
- Skill 平台规则变化风险（依赖 SkillHub/觅游生态）
- 如果 AI Agent 交互范式从"Skill 安装"变成"自然语言意图理解"，策展价值会变化

---

### 候选 2：🎓「Skill 架构师」— Skill 开发教程与方法论 IP

**目标用户**：想自己开发 AI Skill 的产品经理、开发者、设计师——他们看到别人做的 Skill，想自己做但不知道从何下手。

**核心痛点**：Skill 开发缺少系统性方法论。怎么做 Skill 架构？怎么测试？怎么定价？怎么迭代？——这些都是空白领域。

**激活的环**：✅环1 ⚠️环2 ✅环3

**时间窗口**：教程赛道比策展竞争更多，但"Skill 开发"作为教程品类是全新的。

**大公司为什么不追**：Skill 开发教程太"小"，大公司不会为此投入专门的内容团队。

**六维评分**：

| 维度 | 评分 | 说明 |
|------|------|------|
| 痛点强度 | **4** | 想开发 Skill 的人群在增长，但体量小于"想用 Skill"的人群 |
| 杠杆密度 | **4** | 媒体杠杆为主，AI 辅助内容生产 |
| 窗口红利 | **4** | Skill 开发教程品类还在早期 |
| 资源匹配度 | **4** | 跨领域能力匹配，但需先积累 Skill 开发实操经验 |
| 交付标准化程度 | **3** | 教程生产投入较重，标准化程度不如周刊 |
| 现金流潜力 | **4** | 课程/教程变现路径直接 |

**总分：23/30**

**风险点**：教程受众比策展受众窄；需要自己先开发足够多的高质量 Skill 才能建立教学权威性。

### 候选 3：📊「Skill 评测局」— Skill 质量评测体系

**目标用户**：Skill 重度用户和 Skill 开发者——需要客观标准判断哪个 Skill 更好、好在哪。

**核心痛点**：平台评分体系粗糙，缺乏可复现的评测方法论。

**激活的环**：✅环1 ⚠️环2 ⚠️环3

**时间窗口**：评测体系有价值，但更适合作为候选1的增强模块而非独立方向。

**大公司为什么不追**：评测标准难以规模化，需要持续人工判断。

**六维评分**：

| 维度 | 评分 | 说明 |
|------|------|------|
| 痛点强度 | **3** | 评测有价值但不是第一痛点 |
| 杠杆密度 | **4** | 代码+媒体双杠杆 |
| 窗口红利 | **3** | 窗口不独立，依赖策展 IP 建立后 |
| 资源匹配度 | **3** | 评测体系构建能力待建立 |
| 交付标准化程度 | **4** | 评测框架可标准化 |
| 现金流潜力 | **3** | 变现路径较长 |

**总分：20/30**

**风险点**：作为独立利基太小；更适合作为候选1的"产品化延伸"。

## 六、定位陈述

> **「Skill 策展人」** — 在 SkillHub（8万+ Skill）和觅游（4万+ Skill）的供给海洋之上，为 AI Agent 工具的深度用户提供**每周实测精选的 AI Skill 推荐**。不做又一个货架，做那个帮你筛选的人。
>
> **为什么是你**：AI + 产品 + 前端 + 设计四维交叉视角，能同时判断一个 Skill 的技术质量、产品价值、用户体验和设计水准——这是 Skill 策展最稀缺的能力组合。
>
> **为什么现在**：两大 Skill 平台刚过临界规模（供给端成熟），策展层完全空白，先发窗口约 12-18 个月。再等一年，策展内容供给会显著增加。
>
> **为什么大公司不来**：平台方（腾讯/美团）的价值网络是"做大货架"，策展是"做深精选"——天然冲突。工具方聚焦工具层。这个空间只适合"一个人+AI"。
