## 一、组合版价值主张（主推）

### 一句话核心

> **「Skill 策展人」**——在 12万+ AI Skill 的供给海洋中，做那个帮你筛选的人。

### 三层展开

| 层级 | 角色 | 一句话 | 交付 |
|------|------|--------|------|
| **A 入口** | 省时间的人 | 每周 5 分钟，帮你从 12万+ Skill 里挑出真正值得装的 | 免费周刊 |
| **B 壁垒** | 拿结果的人 | 不是推荐 Skill，是给你一个"装了这个 Skill 就能解决的那个问题"的确定答案 | 付费深度合集 |
| **C 底色** | 可信赖的人 | 在谁都可以说"好用"的领域，做那个你真的可以信的人 | 方法论透明 |

### 完整定位陈述

> 「Skill 策展人」为 AI Agent 深度用户提供三层价值：
>
> **入口层**：每周免费周刊，5 分钟了解本周最值得关注的 AI Skill。不堆信息，只做减法。
>
> **壁垒层**：深度实测付费合集，每个 Skill 一份 3000-5000 字完整评测——包含实测过程、场景适配、同类对比、坑点注意。让你做决策时只需要这一份就够了。
>
> **底色层**：公开透明的评测标准和方法论——多维度打分体系、可复现的测试流程、以场景而非技术栈组织的分类体系。让信任来自可验证的过程而非权威。
>
> **你是谁**：一个拥有 AI + 产品 + 前端 + 设计四维交叉视角的独立策展人。不依附任何平台，不拿 Skill 开发者的赞助，只对用户负责。

## 二、差异化锚点

### 与现有方案的差异

| 对手 | 他们说什么 | 我们说什么 |
|------|-----------|-----------|
| 平台排行榜 | "下载量最高的 Skill" | "真正好用的 Skill——实测过，不是刷出来的" |
| AI 博主 | "这个 Skill 好厉害" | "这个 Skill 在什么场景下好用、有什么坑、和同类比好在哪" |
| 社区帖子 | "今天发现一个宝藏" | "每周系统性输出，可追溯、可对比、可信任" |
| 开发者自荐 | "我的 Skill 最棒" | "独立判断，不拿开发者钱，只对用户负责" |

### 不可替代的壁垒

1. **四维交叉判断力**：AI 能力 + 产品思维 + 前端技术 + 设计审美——同时判断一个 Skill 的四个关键维度
2. **方法论透明**：不是"我觉得好用"，而是"我按这个标准测的，你也可以复现"
3. **独立立场**：不依附平台（非官方推荐）、不接受 Skill 开发者赞助（非软文）、不迎合流量（不走标题党）
4. **Agent 驱动的持续输出能力**：策展工作流 60-70% 由 Agent 自动化，保证可持续性

## 三、用户心智占位

### 希望用户怎么记住你

> 当想找一个 AI Skill 时，
> 不是去 SkillHub 刷排行，
> 不是去小红书搜推荐，
> 而是打开「Skill 策展人」的周刊或合集——
> 因为你知道，那里推荐的每一个 Skill 都是真测过的。

### 用户信任公式

```
信任 = (实测深度 × 方法论透明 × 持续一致性) / 商业利益
```

- 实测深度 ↑：装了、跑了、对比了
- 方法论透明 ↑：公开标准、可复现
- 持续一致性 ↑：每期都保持同等的评测质量
- 商业利益 ↓：不拿赞助、不靠平台、独立判断

## 四、不适配的场景（边界声明）

「Skill 策展人」**不适合**以下需求的用户：

| 用户需求 | 为什么不适合 | 替代建议 |
|---------|-------------|---------|
| 想要"所有 Skill 大全" | 我们做减法不做加法 | 直接用 SkillHub/觅游搜索 |
| 想要即时推荐（比如"现在立刻给我推荐 3 个"） | 我们不做到实时响应 | 看历史周刊 |
| 想要免费获取所有深度评测 | 深度评测是付费产品 | 看免费周刊足够了 |
| 想要按技术栈分类的 Skill 目录 | 我们按场景分类 | 平台自带分类 |
| 想要 Skill 开发教程 | 现阶段不覆盖 | 等第二阶段 |
