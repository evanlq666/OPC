# 结论

首批 10 个选题不要追求同一种爆款，而要当作起号反光镜：分别测试 `AI 焦虑`、`AI 最小实践`、`职场提效`、`副业探索`、`个人系统 / 一人公司` 五条内容主线。

# 证据或来源

- 项目定位：`懂产品、懂项目、懂职场`，AI 是杠杆，不是唯一人设。
- 当前状态：0-1 启动期，所有选题均为待验证假设。
- 目标用户：早期职场人、AI 焦虑的普通打工人、想找方向和方法的人。

# 首批 10 个选题

## 1. 你不是不会用 AI，你是不知道让它干嘛

- 主线：AI 焦虑
- 标题方向：你不是不会用AI
- 封面文案：别再问 AI 能做什么
- 开头钩子：很多人学 AI 的第一步就错了，不是先收藏 100 个工具。
- 正文结构：焦虑来自“工具很多但任务不清” -> 举工作场景例子 -> 给一个今天能做的动作：把一个重复任务写成请求。
- 互动提问：你现在最想让 AI 帮你省掉哪件小事？
- 话题：#AI工具 #职场成长 #效率提升 #普通人学AI #打工人
- 风险：别写成 AI 培训广告，重点放在普通人场景。
- 冷启动优先级：高

## 2. 我用 30 分钟搭了一个自己的工作复盘系统

- 主线：个人系统 / 一人公司
- 标题方向：别靠脑子复盘
- 封面文案：30 分钟搭复盘系统
- 开头钩子：工作几年后我发现，很多人不是不努力，是从来没把经验存下来。
- 正文结构：复盘为什么总失效 -> 展示最小系统：记录、分类、提炼、下次复用 -> 给 3 个字段模板。
- 互动提问：你现在复盘是靠文档，还是靠脑子硬记？
- 话题：#工作复盘 #知识管理 #职场方法 #项目管理 #个人成长
- 风险：不要讲太多工具细节，先讲方法和收益。
- 冷启动优先级：高

## 3. 工作 8 年后，我越来越不信“努力就会被看见”

- 主线：职场提效
- 标题方向：努力不一定被看见
- 封面文案：别只会闷头干活
- 开头钩子：这话有点难听，但职场里“被看见”本来就是一项能力。
- 正文结构：努力和可见度是两件事 -> 产品/项目岗位例子 -> 给汇报里的“进展、风险、下一步”三件套。
- 互动提问：你有没有遇到过“活干了，但功劳没被看见”？
- 话题：#职场沟通 #项目管理 #向上管理 #打工人日常 #职场成长
- 风险：避免变成阴谋论，强调建设性表达。
- 冷启动优先级：高

## 4. 如果你想做副业，先别急着做产品

- 主线：副业探索
- 标题方向：副业先别做产品
- 封面文案：先验证需求
- 开头钩子：很多人的副业死在第一步：还没人要，就开始做完整版。
- 正文结构：解释为什么先做内容验证 -> 小红书评论/收藏/私信是信号 -> 最小资料产品可以从一张清单开始。
- 互动提问：你更想做副业，还是先想找到一个可验证方向？
- 话题：#副业探索 #一人公司 #小红书运营 #虚拟资料 #普通人副业
- 风险：不承诺变现结果，不制造焦虑。
- 冷启动优先级：高

## 5. 产品经理转项目经理后，我才懂什么叫“推进”

- 主线：职场提效
- 标题方向：推进不是催人
- 封面文案：推进不是催进度
- 开头钩子：以前我以为推进就是问“做完了吗”，后来发现这很低级。
- 正文结构：推进的本质是让问题往前走 -> 对齐目标、拆阻塞、确认下一步 -> 给一个会议后跟进模板。
- 互动提问：你最烦的推进方式是什么？
- 话题：#项目管理 #产品经理 #职场沟通 #职场经验 #协作效率
- 风险：别攻击具体岗位，写成可复用经验。
- 冷启动优先级：中高

## 6. 普通人学 AI，最该练的不是提示词

- 主线：AI 最小实践
- 标题方向：别只学提示词
- 封面文案：先练任务拆解
- 开头钩子：提示词当然有用，但它不是普通人最该先练的东西。
- 正文结构：提示词只是表达，任务拆解才是底层能力 -> 举写周报/做方案/整理会议纪要例子 -> 给“目标、输入、输出、限制”四格法。
- 互动提问：你用 AI 最容易卡在“问不出来”还是“用不上”？
- 话题：#AI学习 #提示词 #职场效率 #普通人学AI #工作方法
- 风险：避免否定提示词本身，重点是先后顺序。
- 冷启动优先级：中高

## 7. 我为什么开始认真搭自己的 AI 工作台

- 主线：个人系统 / 一人公司
- 标题方向：我开始搭AI工作台
- 封面文案：不是为了炫技
- 开头钩子：我搭 AI 工作台，不是因为喜欢折腾工具，是因为我不想每次都从零开始。
- 正文结构：重复劳动的问题 -> 工作台如何把资料、方法、输出串起来 -> 说明它服务内容、项目和副业实验。
- 互动提问：你最想把哪类工作流程自动化？
- 话题：#AI工作流 #知识库 #个人系统 #效率工具 #一人公司
- 风险：技术细节不要过重，避免劝退。
- 冷启动优先级：中高

## 8. 一个判断：你适不适合现在做个人 IP

- 主线：副业探索
- 标题方向：你适合做个人IP吗
- 封面文案：先看这 3 点
- 开头钩子：不是每个人都适合立刻做个人 IP，尤其别被“普通人也能做”冲昏头。
- 正文结构：有无稳定议题、有无真实经历、有无持续输出场景 -> 不适合时先做积累 -> 适合时先做 30 天试验。
- 互动提问：你现在更卡在定位、选题，还是不敢发？
- 话题：#个人IP #内容创作 #副业探索 #小红书起号 #普通人做IP
- 风险：不要打击用户，给替代路径。
- 冷启动优先级：中

## 9. 职场新人最该补的，不是情商，是交付感

- 主线：职场提效
- 标题方向：新人先练交付感
- 封面文案：别只说“我尽力了”
- 开头钩子：很多新人不是态度差，是交付感太弱，让别人不放心。
- 正文结构：交付感是什么 -> 举反例：只说在做、没节点、没风险提示 -> 给交付回复模板。
- 互动提问：你最怕同事怎么回复你？
- 话题：#职场新人 #工作方法 #职场沟通 #项目协作 #打工人
- 风险：别爹味说教，用“过去我也踩过”的视角。
- 冷启动优先级：中高

## 10. 我想做一人公司，但我先从一张表开始

- 主线：个人系统 / 一人公司
- 标题方向：一人公司先从一张表开始
- 封面文案：别先注册公司
- 开头钩子：一人公司听起来很大，但对普通人来说，第一步可能只是一张验证表。
- 正文结构：一人公司不是口号 -> 表里记录内容、反馈、需求、资料候选 -> 用 4 周跑最小闭环。
- 互动提问：如果给你一张“一人公司验证表”，你最想先验证什么？
- 话题：#一人公司 #个人商业模式 #副业探索 #内容IP #虚拟资料
- 风险：别把“一人公司”讲得太宏大，落到具体动作。
- 冷启动优先级：高

# 可复用点

- 起号首批不要只发 AI，也不要只发职场，要用 5 条主线做方向测试。
- 高优先级题目优先覆盖：AI 焦虑、工作复盘、努力被看见、副业验证、一人公司验证。
- 每条都保留互动问题，为后续评论区和虚拟资料候选判断收集信号。
