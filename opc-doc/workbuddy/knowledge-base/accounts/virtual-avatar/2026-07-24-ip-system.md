# 虚拟形象作为 IP 记忆点

## 一句话结论

`Evan下班了` 可以使用一个长期稳定的虚拟形象，但它应当是 Evan 的“视觉分身”，而不是脱离真实经历的可爱吉祥物。最适合的方向是：低饱和、半写实手绘的下班互联网产品/项目人，用固定人物特征和固定工作场景承载真实的焦虑、试错和产出。

## 证据或来源

- 当前账号主线是 `懂产品、懂项目、懂职场`，内容表达已经确定采用第一人称自我实验，而不是站在老师位劝别人不要焦虑。
- 当前 AI 焦虑内容的叙事规则是：`我为什么焦虑 -> 我做了什么 -> 产出或卡点 -> 下一步怎么跟进`。
- 已有的白底卡片风和小黑插画可以承载信息，但前者偏知识卡片，后者与 Evan 的个人身份绑定不够强。
- 2026-07-24 对话中确定：虚拟形象的目标是增加记忆点，同时保持真实和可信；首篇将围绕“刷到 AI 裁员新闻后开始代入”展开，后续跟进一次真实图文实验。

## 形象定位

### 角色定义

> 一个看到 AI 变化会不安，但愿意在下班后亲自试一遍的互联网人。

### 固定气质

- 真实、克制、略疲惫，但仍然在做事。
- 不摆出 AI 专家姿态，不用未来科技英雄叙事。
- 有一点自嘲和观察感，但不靠夸张表情制造廉价戏剧性。

### 推荐视觉风格

- 半写实手绘插画。
- 低饱和灰蓝、米白、暗红或橙色点缀。
- 普通衬衫、T 恤、电脑包等日常服装。
- 保留 Evan 本人的稳定特征，例如发型、眼镜、胡须或脸型；具体特征以当前头像/本人参考图最终确认。
- 场景以办公桌、地铁、出租屋、咖啡店等真实环境为主。

### 不建议使用

- 赛博朋克、机器人、未来战士、液态玻璃等强 AI 视觉。
- 过度可爱的儿童感卡通。
- 每次随机变化脸型、发型、服装和年龄。
- 把小黑或通用卡通角色直接当成 Evan 的长期主角。

## 需要锁定的角色参数

正式批量制作内容前，先建立一套角色基准图和角色规范，至少锁定：

- 年龄区间、体型和人物比例。
- 发型、脸型、眼镜、胡须等人物特征。
- 常用服装和固定配色。
- 线条粗细、阴影方式和背景质感。
- 常用道具：电脑、手机、电脑包、任务清单、咖啡杯等。
- 常用情绪：疲惫、犹豫、认真、返工、松一口气。
- 禁止出现的元素：机器人化、过度科技化、夸张成功姿态、无关品牌和虚假工作成果。

建议基准图至少包含：正面、侧面、45 度、电脑前坐姿、刷手机焦虑、开始行动、完成后复盘等姿态。

## 内容中的使用规则

虚拟形象负责记忆和叙事，真实内容负责建立信任。不要每页都放角色，也不要让角色替代事实。

推荐图文比例：

1. 封面：角色出现，负责形成识别。
2. 情绪页：角色处于具体场景，例如深夜刷到 AI 裁员新闻。
3. 过程页：用桌面、任务清单、修改痕迹和工具界面承载内容。
4. 结果页：展示真实产出、返工或尚未完成的状态。
5. 结尾页：角色继续实验，而不是摆出“问题已经解决”的姿态。

固定叙事链：

```text
看到消息或问题
-> 开始代入和焦虑
-> 下班后选一件小事
-> 实际尝试并遇到卡点
-> 留下产出、返工记录或失败结论
```

## 生图工作流

不要每次从零生成角色，也不要只依赖一段固定提示词。后续统一采用：

```text
角色基准图
+ 本篇具体场景
+ 本篇情绪和动作
+ 页面文字与构图要求
```

每次生成新场景时，优先以同一张角色基准图作为参考；能够编辑已有图时，优先编辑而不是完全重生。每次生成后检查人物脸型、发型、眼镜、服装、比例和线条是否漂移。

建议资产目录：

```text
assets/character/evan-avatar/
├── character-sheet.png
├── portrait.png
├── front.png
├── side.png
├── sitting-at-desk.png
├── expressions/
├── poses/
├── props/
└── character-style-guide.md
```

## 首篇应用方向

首篇暂定为：

> 刷到 AI 裁员新闻后，我开始认真想自己的退路。

虚拟形象的动作顺序：

1. 深夜刷到消息，表情停住。
2. 回到电脑前，把自己代入岗位变化。
3. 打开任务清单，决定先做一个真实的小实验。
4. 制作图文时出现返工和卡点。
5. 留下一个尚未完美但真实存在的产出。

这篇不能借形象制造“不会 AI 就会失业”的恐慌，也不能把一次图文制作包装成成功案例。

## 风险或边界

- 虚拟形象只能视觉化 Evan 真实经历，不能替 Evan 编造经历、结果、收入或案例。
- 角色太可爱会削弱职场可信度，角色太科技会把账号带向 AI 工具号。
- 形象统一不等于每篇画面相同；人物参数固定，场景、动作和情绪应随实验变化。
- 首篇承诺跟进后，后续必须真实记录过程、产出和返工，否则记忆点会变成包装感。
- 角色基准图未确认前，不应批量生成大量页面，以免后续返工。

## 下一步动作

1. 以当前头像或本人参考图为人物结构依据，确定 1 个主视觉方案。
2. 生成角色基准图：正面、侧面、45 度和 4 个常用情绪/动作。
3. 写入 `character-style-guide.md`，锁定人物参数、配色、服装、道具和负面提示词。
4. 用角色基准图重做首篇“刷到 AI 裁员新闻后开始代入”的图文。
5. 在批量制作前检查手机端识别度、人物一致性和是否仍然像真实职场记录。
