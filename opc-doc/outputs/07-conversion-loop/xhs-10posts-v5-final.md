# 第2篇：8年PM告诉你，AI焦虑的真相

### 选题类型
🎯 **反常识型**

### 最佳标题

备选：被AI焦虑轰炸了半年，一个8年PM的冷静分析
备选：刷了100篇AI焦虑文，发现一个问题——写的人大多不是做产品的

### 选题触发
- 触发器：认知冲突（8年PM的视角 ≠ 主流叙事） + 权威借力（8年PM）
- 五检：≤20字 ✓ / 悬念"真相是什么" ✓ / 痛点"AI焦虑" ✓ / 更大用户词"8年产品" ✓ / 2+张力"被取代 vs 真相" ✓

### 三问校验
- 谁的问题？ → 有工作经验但被AI焦虑冲击得自我怀疑的人
- 为什么点？ → "8年PM"有专业权重，"真相不是…"制造认知缺口
- 带走什么？ → 一个更冷静的判断框架：AI替代的是任务，不是判断力

### 核心机制
> 不是"别焦虑了"，而是"焦虑没错，但你焦虑错了方向"。核心论点：AI替代的是执行层任务，但"判断什么值得做"这件事，反而更需要有经验的人。

### 正文

做了8年产品，最近半年被问最多的一句话是——"AI会不会取代产品经理？"

我的答案是：取代产品经理的不是AI，是用AI的产品经理取代不用AI的产品经理。但"判断力"这件事，AI做不了。

我说三个真实感受：

**1. AI替代的是"执行"，不是"判断"**

我上个月用AI做了一个功能模块的原型，从需求文档到可交互demo，3个晚上。如果走正常流程——写PRD→评审→等设计→等开发——至少两周。AI帮我把"执行"压缩了，但"判断这个功能该不该做、用户需不需要、商业上划不划算"——这些事AI给不了答案。

能做好判断的人，反而因为AI变得更稀缺了。

**2. 你过去8年没有白干**

你的行业认知、用户洞察、沟通能力、项目管理经验——这些不会因为AI出现就清零。反而，会用AI的人里，有行业经验的人跑得最快。因为他们知道该让AI做什么。

**3. 真正的焦虑来源不是AI，是你的技能结构**

如果你做了8年只做"执行"——写文档、画原型、排期——那确实该焦虑。但如果你一直在积累"为什么做"和"做什么"的判断力，AI只会让你的效率更高。

所以我现在不焦虑了。不是因为AI不可怕，是因为我知道自己该积累什么。

你的工作里，哪些是AI替代不了的？评论区聊聊。

### 正文

先声明：我不会写代码。不是"会一点"的那种不会，是真的不会。CSS和HTML的区别我都是上个月才搞清楚的。

但上周末，我花了3个小时，做了一个能用的产品——情绪日记小程序。

事情是这样的。我一直想做一个小工具，记录每天的情绪变化，看看有没有什么规律。以前这种想法出现之后的标准流程是——记在备忘录里 → 下次开会提一下 → 排期 → 等开发 → 忘了。

这次我换了个方法。

**第1步（30分钟）**：用Cursor（一个AI编程工具）描述需求。不是写代码，是真的一行代码都没写——就像跟产品助理说话一样，告诉它"我要一个情绪日记小程序，用户可以选5种emoji记录心情，每天一条，有周视图和月视图"。

**第2步（1.5小时）**：AI开始生成代码。中间它出了3个bug——一个页面的颜色全乱了，一个保存按钮按了没反应，一个图表根本不显示。每次出问题我就截图+描述问题，让它自己改。像一个产品经理在提bug。

**第3步（1小时）**：功能都跑通了之后，我开始"验收"。改了5个交互细节，加了2个我临时想到的功能。还是没写代码——就是告诉AI我想要什么效果。

3小时后，一个能记录情绪、有图表展示、数据存本地的小程序，跑起来了。

说实话，我拿到可以用的那一刻，手是有点抖的。

不是因为多厉害——这个小程序比市面上任何同类产品都简陋。而是因为，一个做了8年产品的人，第一次不需要等开发排期，自己在周末晚上把一个想法变成了可运行的东西。

这就是我开始"一人公司"实验的起点。

后面我会继续做更多产品。如果你也有想做但一直没做的产品想法，留言告诉我——说不定下一个就是我们一起做。

我第一周列了5个产品想法，其中一个是"AI竞品分析工具"。搞了两个晚上发现，AI对行业数据根本不了解，分析深度达不到我要的标准。两个晚上白费。

现在我的原则：第一版2-3小时做不出来就砍。先用最小版本验证思路，有用再迭代。

**坑2：太信AI给的数据**

做方案的时候让AI帮我找"2025年中国SaaS市场规模"，它给了一串看起来很专业的数字。我差点直接用了。后来自己去查，发现数据对不上——它编的。

现在：AI给数字必核实。创意类和语言类的东西可以放心用。

**坑3：代码改了但是不知道改了什么**

做情绪日记的时候让AI修了一个bug，修好了。但过两天另一个功能出问题的时候，我完全不知道之前的修改影响了什么。因为我没让AI写注释。

现在：每次改完代码，加一句"解释一下你做了什么修改，为什么"。

**坑4：计划太满，周三就崩了**

我第一周排了每天1.5小时，结果周三加班到9点，回家直接瘫了。断了一天之后，负罪感反而让我后面两天也不想做。

现在：允许自己断。断了就断了，第二天继续，别让完美主义毁了持续性。

**坑5：只知道问AI，不知道让AI问我**

前两周我都是单向提问。后来发现，让AI反过来问我——"你觉得这个产品还需要考虑什么"——比自己闷头想高效得多。

现在：每完成一个产品初版，让AI列5个问题来挑战我。

---

最后说一个数据：半个月来，我实际做了13天（断了2天），做了2个产品，写了9篇笔记。跟那些"30天做10个产品"的大神比不了，但对我来说，这个节奏是可持续的。

**可持续 > 可炫耀。**

**🔧 我的一人公司工具链（7个工具，全免费）**

**1. Notion — 我的第二大脑**
用途：周报模板、项目看板、灵感收集、阅读笔记
免费版就够了。我建了四个数据库：产品想法库、周报模板、AI使用技巧库、竞品学习库
→ 替代：Excel + Trello + Evernote

**2. Kimi — 我的AI助手**
用途：长文档阅读、思路梳理、翻译、资料整理
为什么不用ChatGPT？因为国内手机直接能用，长文阅读功能太强
→ 替代：搜索引擎 + 翻译软件 + 第一版头脑风暴对象

**3. Cursor — 我的AI开发**
用途：0代码做产品。不需要学编程，会描述需求就行
适合：做原型验证、做个人工具、做展示页面
→ 替代：等开发排期

**4. 飞书文档 — 我的内容生产系统**
用途：写小红书文案、排期管理、配图素材库
我建了一个内容模板：标题+正文+配图描述+标签+发布时间，每次新建一行
→ 替代：散落的备忘录+截图文件夹

**5. Canva — 我的设计助手**
用途：小红书封面、产品截图标注、简单的图表
免费版够用。我有3个封面模板轮换用，保持视觉一致性
→ 替代：等设计师排期

**6. GitHub — 我的产品仓库**
用途：存代码、部署网页、记录版本
和Cursor配合使用，AI写完代码自动提交
→ 替代：U盘存代码（别笑，我以前真的这么干）

**7. 微信输入法的语音转文字 — 我的灵感捕获器**
用途：路上想到什么立刻说，回家再看
比打字快太多，而且能保留口语的自然感
→ 替代：备忘录打字
