**★ 看到大厂提AI裁员，我在笔记本上画了两条路**

### 封面

### 正文

那天晚上刷到裁员新闻，我盯着屏幕愣了几秒。

然后我做了件很奇怪的事——打开笔记本，画了两条线。

一条往上，写了个"学Agent"。一条往右，写了个"用Agent做副业"。

往上那条：学Agent的原理，知道这东西怎么思考、怎么调用工具、怎么自己完成任务。以后每个公司都需要能把重复工作交给Agent的人。我要做那个人。这样的话，公司裁不了我。或者裁了我，我也有地方去。

往右那条：同样的能力，白天保饭碗，晚上找退路。用Agent搭小工具、生成内容、做自动化工作流。这些不急着赚钱——但如果有一天路被封了，这条我自己踩出来的路，就是退路。

画完这两条线，我反而冷静了。不是因为有了什么了不起的计划。是因为"我不知道该怎么办"变成了"我有两件事可以开始做"。

从那天开始，我每天下班后给自己2小时。不是学AI，是做AI。好的坏的，都会记录在这里。

关注我，看一个普通人能走多远。


### 正文

凌晨一点，刷到某大厂的内部邮件。"组织架构优化，AI相关投入增加30%。"

我把手机翻过来扣在桌上，盯着天花板。

不是怕被裁。是怕被裁的时候，我除了"再找一份工作"没有别的选择。那种感觉像站在悬崖边，往下看全是雾——你不知道下面是水还是石头。

我起来开了灯，在笔记本上开始写。不是写焦虑，是写"如果最坏的情况发生，我有什么"。

写到最后，只有两样东西：
1. 我还没学的Agent——但我知道这是方向
2. 我还没做的副业——但我知道可以做

够了。两条路。

第一条：学Agent。不是学提示词，是学怎么让AI自己完成一整个任务。这件事的工作岗位才刚刚开始出现——在所有人都没准备好的时候你就是专家。

第二条：用Agent做副业。不再等到"准备好了"才开始——今晚就开始。做一个小工具，哪怕只有我自己用。做一个内容号，哪怕只有10个粉丝。

我不是专家。我只是一个不想被动等着的普通人。接下来我会记录每晚的真实实验——翻车了也会写。

## 版本C：「先给结论」——最直接、最有行动力

### 标题
**★ AI裁员时代，普通人有且只有两条路**

备选：别焦虑了，你只需要做两件事
备选：想清楚这两条路之后，我的AI焦虑好了

### 封面
```
深蓝渐变背景 + 一个分叉路口简笔画
白色大字：普通人有且只有两条路
底部标签：AI焦虑 01
```

### 正文

先说结论：AI焦虑没用。想清楚两条路，然后开始走，才有用。

**路1：成为Agent的使用专家。**

不是"会用AI聊天"，是会让AI自己干活。Agent——能自己思考、自己调用工具、自己完成任务的AI。以后每个公司都需要能把重复工作交给Agent的人。这个岗位现在还没被定义，你先坐上去了，你就是标准。

**路2：用Agent给自己造一条退路。**

同样的技能，白天上班用是保饭碗，晚上下班用是找退路。Agent能做小工具、能自动生成内容、能搭工作流——这些东西都是能变成收入的。你现在开始做，不是为了马上赚到钱。是为了哪一天你的主业出了问题，你不是"完了"，而是"换一个方向继续走"。

两条路用的是同一套能力。一边安全，一边自由。

我选择了同时走。每天下班后2小时，一半花在学Agent上，一半花在用Agent做自己的东西上。从今天开始记录，看一个普通人能不能走出来。

## 版本D：「故事倒叙」——最反套路、最有悬念

### 标题
**★ 我是怎么从一个焦虑的打工人变成Agent实践者的**

备选：三个月前我还在焦虑AI，现在我每晚都在跑Agent
备选：当我决定把焦虑变成实验之后，一切都变了

### 封面
```
深蓝渐变背景 + 一个翻页日历对比
左侧日历：焦虑、刷新闻、收藏教程
右侧日历：学Agent、跑实验、做副业
大字标题：我是怎么转过来的
```

### 正文

三个月前：刷到AI新闻→收藏→焦虑→再刷→更焦虑→失眠。

现在的状态：每天下班后打开Coze→搭Agent→跑实验→记录→发笔记。

怎么转过来的？因为我想明白了一件事。

**焦虑不是一个情绪问题，是一个信息问题。** 你焦虑是因为你不知道"AI能替代我什么"和"我能用AI做什么"。这两个问题的答案，网上找不到——只能自己去试。

所以我做了一个很简单的决定：下班后不是刷AI教程，是做AI实验。每周一个。就一个。

现在做到第X个了。做了Agent整理聊天记录、Agent自动写周报、Agent帮我做竞品简报。有些跑通了，有些跑崩了。但每一个，都让我对AI的理解比刷100篇教程更深。

**最重要的是心态变了：从"AI会不会替代我"变成了"我能不能让Agent帮我多做点事"。第一个问题让你焦虑，第二个问题让你行动。**

现在我把它总结成两条路，公开记录。不是为了证明什么——是为了让你看到，一个普通人是真的可以走出来的。

### 评论区引导
"你现在的状态是三个月前的我，还是现在的我？"

## 版本E：「反向提问」——最互动、最引发评论

### 标题
**★ 如果明天公司因为AI把你裁了，你手里有什么？**

备选：先别着急收藏AI教程，回答我一个问题
备选：这个问题我问了自己三遍，每一遍答案都不一样

### 封面
```
深蓝渐变背景 + 问号
白色大字：如果明天因为AI被裁
副标题：你手里有什么？
底部标签：AI焦虑 01
```

### 正文

先别往下刷。停下来想三秒钟。

**如果明天公司因为AI把你裁了，你手里有什么？**

不是问"你会再找到一份工作吗"。是问——除了简历上那几行字，你还有没有其他东西？一个能变成收入的技能、一个已经在跑的副业、一个被你验证过的方向？

我问了自己这个问题，第一遍的答案是：**什么都没有。**

第二遍，我开始翻自己平时在干嘛。嗯……会用一点AI，搭过几个Agent，做过一个小工具。但都是"玩一下"，没认真对待过。如果明天被裁，这些东西能不能撑一个月？不能。

第三遍，我在笔记本上写了两条路。

**路1：把Agent变成硬技能。** 不是"会一点"，是能从零搭出一个能用的Agent。这件事的工作岗位在增长，在所有人都没准备好的时候学到足够深——你就不可替代。

**路2：把Agent变成收入来源。** 不是"想到一个点子"，是真的做出来→让人知道→让人愿意付费。哪怕一个月只有几百块，那也是你自己赚的。

这两条路，我同时开始走了。每天下班后记录进展。不为了写给别人看——为了万一哪天被问"你手里有什么"的时候，我不用想三遍。

现在轮到你了：**如果明天被裁，你手里有什么？**
