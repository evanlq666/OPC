## 二、核心对标深度拆解（框架层）

> ⚠️ 无法直接抓取小红书内容，以下基于描述+SOP推断。建议你在小红书上直接搜这些账号，用以下框架自己拆。

### 拆解框架（每篇内容）

```
封面：标题占比？主视觉？色调？
标题：句式类型（疑问/数字/对比/直接承诺）
开头三句：怎么钩住人？
正文结构：总分？清单？对比？故事？
停留理由：哪里信息密度最高？
收藏理由：哪里让人想"存下来以后用"？
结尾CTA：关注/评论/私信引导？
标签组合：大流量词 vs 精准词配比？
```

### 斑马MVP实验室 — 最近接你的方向

**推测内容骨架**：
- 封面风格：产品原型截图/对比图/结构图 → 信息密度高
- 标题公式（推测）：`[痛点场景]+[用AI做了XX]+[结果]` 或 `[大厂面试题]+[AI解法]`
- 开头：直接展示成品或面试题，3秒建立"这条有用"
- 正文：过程拆解（不是炫技，是教方法）→ 你的"用产品思维跟AI说话"可以走同样的结构
- 收藏理由：流程图/SOP/可复用的Prompt模板
- CTA：引导评论"你想用AI做什么产品？"

**你的复用方案**：
```
斑马的「AI做MVP」→ 你的「AI驾驶舱」
斑马的「产品面试拆解」→ 你的「用产品思维跟AI说话」
斑马的「成品展示」→ 你的「图文测评+可操作步骤」
```

### 一乐Yile — SOP式内容结构

**推测内容骨架**：
- 内容形态：长图文，结构极度清晰（步骤1/2/3/4）
- 标题公式：`[场景]+[SOP/方法论/模板]+[结果承诺]`
- 正文：场景→痛点→方法→步骤→模板→总结
- 收藏理由：SOP流程图、检查清单 → 天然收藏型内容
- 人设：不是"教你"，是"这是我的做法，你看看适不适合你"

**你的复用方案**：
```
一乐的「产品SOP」→ 你的「用产品思维跟AI说话」
例如：「PM怎么跟AI开需求评审？我的4步SOP」
       「我用写PRD的方法写Prompt，效率翻了3倍」
```
