# 阶段06：MVP实验设计 · 终稿

> 设计师：验真（mvp-designer）
> 日期：2026-07-16

## H1核心假设验证方案：「0行代码1个产品」2集短视频

### MVP定义

**核心实验**：2集"0行代码1个产品"系列短视频，小红书为主、抖音为辅。
- Episode 1：情绪日记小程序（测"会不会看"）
- Episode 2：个人作品集网站（测"会不会回来"）

**为什么是这个形式**：只有"跟做"行为能直接测量H1，"内容消费"测不出来。

### 4周内容矩阵

| Week | 内容 | 目的 |
|------|------|------|
| W1 | Episode 1 + 图文笔记 | 首发吸引力 |
| W2 | 周更："用产品思维跟AI说话" | 保持存在感 |
| W3 | **Episode 2**（核心数据点） | 测量回流率 |
| W4 | 周更："AI驾驶舱" + H1复盘 | 总结评估 |

### 成功/失败标准

**Episode 2核心判定**：
- ✅ **回访观众占比>25%** + ≥5条"跟做"反馈 → H1通过
- ❌ 回访率<15% + 0条跟做反馈 → H1失败，PIVOT

### 第一周行动计划（逐天）

| 天 | 核心任务 | 耗时 |
|----|---------|------|
| Day 1（周四）| 选题定型 + 小红书装修 | 4h |
| Day 2（周五）| Vibe Coding实录 + 录制旁白 | 5h |
| Day 3（周六）| 精剪 + 图文笔记 + 抖音适配 | 4.5h |
| Day 4（周日）| 20:00发布 + 2h黄金互动 | 2.25h |
| Day 5（周一）| 数据观察 + 内容储备 | 2.5h |
| Day 6（周二）| 互动深化 + 公众号文章 | 1.75h |
| Day 7（周三）| 72h数据复盘 + 决策 | 1.5h |
| **合计** | **约21.5h** | |

### 止损机制（6个信号）

| 信号 | 触发条件 | 动作 |
|------|---------|------|
| 首集哑火 | 72h播放<100，收藏<10 | 换标题重试→若仍无效→PIVOT到方向④ |
| 受众错配 | 评论都是"大佬"而非"怎么做" | Episode 2降低门槛，标题加"手把手" |
| 有播放无转化 | 播放>500但新增粉<20 | 强化CTA + 关注后送工具清单 |
| 回流失败 | E2回访<15% | **H1 FAIL，正式PIVOT** |
| 抖音掉粉加速 | 净掉粉>10 | 抖音降为10%投入，全砸小红书 |
| 精力溢出 | 连续两周>18h | 砍公众号、降周更为快剪 |

### H2并行建议：可以同步做

- 在周更内容中随机嵌入AI视频B-roll做灰度A/B测试
- 隔周交替：一周有AI视频，一周无
- 零额外成本，4周收4组对比数据
- **不污染H1信号**（H1主实验Ep1/Ep2不掺AI视频）
