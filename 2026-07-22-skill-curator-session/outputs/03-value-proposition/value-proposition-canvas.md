## 二、Value Map（价值地图）

### Products & Services（产品与服务）

| ID | 产品/服务 | 层级 | 形态 | 定价 |
|----|----------|------|------|------|
| PS1 | 「Skill 策展人」免费周刊 | A 入口 | 每周推送 3-5 个 Skill 简评 | 免费 |
| PS2 | 付费精选合集 | B 壁垒 | 单个 Skill 深度评测 3000-5000 字 | 29.9-59.9 元 |
| PS3 | 品牌信任资产 | C 底色 | 公开评测标准 + 评测方法论 + Skill 分类体系 | 免费 |
| PS4 | 自有 Skill 产品 | 未来 | 基于策展洞察开发的 Skill | 待定 |

### Pain Relievers（痛点消除）

| 对应痛点 | 消除方式 | 产品 |
|---------|---------|------|
| P1 信息过载 | 每周只推 3-5 个——做减法而非加法 | PS1 免费周刊 |
| P2 评分不可信 | 公开评测标准 + 实测可复现 → 信任来自方法论透明 | PS3 品牌信任资产 |
| P3 场景匹配困难 | 评测以「场景」为第一维度，先回答「你是什么场景」 | PS2 付费合集 |
| P4 隐性缺陷 | 实测中专项验证版本兼容、边界条件、同类对比下的不足 | PS2 付费合集 |
| P5 缺乏跟踪 | 周刊持续追踪已推荐 Skill 的更新/弃坑状态 | PS1 免费周刊 |
| P6 难对比 | 付费合集设「同类对比」固定模块 | PS2 付费合集 |
| P7 描述难懂 | 用场景语言而非技术术语写评测 | 全部 |
| P8 中英文混杂 | 标注语言、本土化程度 | 全部 |

### Gain Creators（收益创造）

| 对应收益 | 创造方式 | 产品 |
|---------|---------|------|
| G1 节省时间 | 周刊 = 用户每周 5-10 分钟，筛选工作由策展人完成 | PS1 免费周刊 |
| G2 可靠判断 | 实测 = 装了、跑了、对比了，不是看了描述觉得不错 | PS2 付费合集 |
| G3 场景推荐 | 每个 Skill 标注适合/不适合场景 | PS1 + PS2 |
| G4 横向对比 | 付费合集中「同类对比」固定模块 | PS2 付费合集 |
| G5 避坑指南 | 每个评测含「坑点与注意」模块 | PS2 付费合集 |
| G6 Skill 组合 | 中后期推出「Skill 工作流」协同推荐 | PS2 扩展 |
| G7 生态动向 | 周刊中「生态动向」板块 | PS1 免费周刊 |
| G8 发现未知需求 | 场景化推荐让用户发现新可能 | 全部 |
| G9 信任延伸 | 持续一致的评测质量 → 认知外包 | PS3 品牌信任资产 |

## 三、Fit（匹配验证）

### 问题-方案匹配

```
痛点 P1（信息过载）  ←→  PS1（免费周刊做减法）
痛点 P2（评分不可信） ←→  PS3（方法论透明）
痛点 P3（场景匹配难） ←→  PS2（场景化深度评测）
```

### 产品-市场匹配

```
目标客群：AI Agent 深度用户，有主动安装 Skill 行为
核心需求：可信赖的筛选 → 节省决策时间
价值交付：免费周刊（入口）→ 付费合集（壁垒）→ 品牌信任（底色）
```

### 商业模式匹配

```
免费周刊（获客 + 信任建设）
    ↓ 4-8 周后
付费合集（变现 + 壁垒强化）
    ↓ 6-12 月后
自有 Skill（利润放大 + 生态位升级）
```

## 四、竞争对比

| 对比维度 | 平台排行榜 | AI 博主推荐 | 社区帖子 | **Skill 策展人** |
|---------|-----------|------------|---------|-----------------|
| 筛选深度 | 浅（按分排序） | 浅（一句话推荐） | 随机 | **深（3000-5000字实测）** |
| 可信度 | 低（可刷榜） | 中（可能赞助） | 不可控 | **高（方法论透明）** |
| 场景匹配 | 无 | 偶尔 | 偶尔 | **系统化（以场景为第一维度）** |
| 持续跟踪 | 不跟踪 | 不跟踪 | 不跟踪 | **持续跟踪更新状态** |
| 同类对比 | 无 | 无 | 偶尔 | **固定模块** |
| 更新频率 | 实时 | 不固定 | 不固定 | **每周** |
