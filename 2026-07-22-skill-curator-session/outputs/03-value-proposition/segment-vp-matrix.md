## 一、客群-价值主张对应关系

| 客群细分 | 核心诉求 | 对应价值主张 | 产品层级 | 优先级 |
|---------|---------|-------------|---------|--------|

## 二、分层策略详解

### 三层结构

```
C 底色：「可信赖的人」— 降风险型
├── 目标：让用户信任策展人的判断
├── 交付：公开评测标准、方法论透明、持续一致性
├── 节奏：从第一天开始，贯穿始终
└── 指标：用户引用率、口碑传播率

B 壁垒：「拿结果的人」— 结果型
├── 目标：用户愿意为深度评测付费
├── 交付：单个 Skill 3000-5000 字完整评测（实测+对比+坑点）
├── 节奏：周刊运营 3-6 月后上线
└── 指标：付费转化率、复购率、客单价

A 入口：「省时间的人」— 提效型
├── 目标：用户第一次接触并记住「Skill 策展人」
├── 交付：每周免费周刊，3-5 个 Skill 简评
├── 节奏：Day 1 启动
└── 指标：订阅量、打开率、分享率
```

## 四、客群扩展路径

```
阶段 1（0-6 月）：AI Agent 深度实操型
    ├── 目标：建立策展 IP 认知 + 积累信任
    ├── 产品：免费周刊 + 品牌信任资产
    └── 变现：开始尝试付费合集

阶段 2（6-12 月）：扩展到 Skill 开发者
    ├── 触发：策展 IP 成熟后自然吸引开发者关注
    ├── 产品：Skill 开发方法论 + 评测反馈
    └── 变现：开发者工具 + 推广服务

阶段 3（12+ 月）：扩展到 AI 小白
    ├── 触发：Skill 概念普及 + 策展 IP 已有权威
    ├── 产品：Skill 入门指南 + 场景化 Skill 套餐
    └── 变现：入门课程 + Skill 推荐佣金
```

**原则**：先深后广，先服务最需要你的人，再逐步扩展覆盖范围。
