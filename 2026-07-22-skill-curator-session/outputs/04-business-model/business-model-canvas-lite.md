## 一、价值主张（Value Propositions）

> Lean Canvas UVP 已覆盖，此处做 BMC 视角补充

### 价值创造逻辑

```
创始人能力（AI×产品×前端×设计）
    ↓
四维实测 Skill 评测（信息筛选 + 场景匹配 + 避坑）
    ↓
用户获得：决策时间节省 + 踩坑风险规避 + 前沿认知更新
```

### 对不同客群的价值

| 客群 | 核心价值 | 付费意愿 |
|------|---------|---------|
| AI Agent 深度实操型用户 | 节省筛选时间 + 可靠决策依据 | 中-高（¥29.9-59.9） |
| AI 工具推广者/布道者 | 可引用的独立判断来源 + 传播素材 | 低-中（免费就够了） |

## 二、客户关系（Customer Relationships）

### 关系类型

| 关系类型 | 实现方式 | Agent自动化 |
|---------|---------|------------|
| **自助服务** | 免费周刊订阅、付费合集自助购买 | 🤖 全自动 |
| **社区互动** | 即刻/X 评论区互动、周刊读者反馈 | 🤖 70%（AI草稿+人工审核） |
| **个人触达** | 深度用户一对一交流、付费用户专属反馈通道 | 👤 人工 |
| **共创** | 邀请种子用户参与评测标准讨论 | 👤 人工 |

### 客户留存策略

```
新读者 → 周刊持续价值输出（每周必看）
    ↓
活跃读者 → 互动反馈（评论回复、Skill推荐请求）
    ↓
付费用户 → 专属通道（优先响应推荐请求、更新通知）
    ↓
超级用户 → 共创（参与评测标准迭代、内测新合集）
```

## 四、关键资源（Key Resources）

| 资源类型 | 具体内容 | 是否可被复制 |
|---------|---------|------------|
| **人力** | 创始人的四维交叉判断力 | 短期内难以复制 |
| **智力** | 评测方法论 + Skill分类体系 + 知识图谱 | 随时间积累加深壁垒 |
| **技术** | Agent 驱动的策展工作流 | 方法论本身可被复制，但执行效率差 |
| **品牌** | 「Skill策展人」信任资产 | 一旦建立，切换成本高 |
| **社区** | 种子用户群体（高质量反馈源） | 需要时间积累 |

## 五、关键伙伴（Key Partnerships）

| 伙伴类型 | 具体角色 | 合作方式 |
|---------|---------|---------|
| **Skill 平台**（SkillHub/觅游） | Skill 供给源 + 潜在分发渠道 | 非正式（现阶段不需要官方合作） |
| **AI 工具社区** | 种子用户来源 + 传播节点 | 内容贡献 + 互动 |
| **Skill 开发者** | 评测对象 + 潜在反馈来源 | 信息获取（独立评测，不接受赞助影响） |
| **分发平台**（公众号/即刻/小报童） | 内容分发基础设施 | 平台规则内运营 |

### 关键独立性原则

> Skill策展人的核心价值在于**独立性**。与 Skill 开发者/平台的关系必须保持"一臂距离"——不接受赞助评测、不因合作关系影响推荐判断。这是 C 底色层（品牌信任）的基础。

## 九、成本结构（Cost Structure）

> Lean Canvas 已详细覆盖，BMC 补充成本类型分析

### 成本驱动 vs. 价值驱动

Skill 策展人是典型的**价值驱动型**商业模式：
- 固定成本极低（¥150-550/月）
- 主要投入是创始人的时间（价值驱动）
- 收入不依赖规模，依赖深度和信任（边际成本不随用户数增长）

### 盈亏平衡分析

| 阶段 | 月固定成本 | 月收入预估 | 盈亏状态 |
|------|-----------|-----------|---------|
| 0-3月 | ¥200-500 | ¥0 | 🔴 纯投入 |
| 3-6月 | ¥200-500 | ¥500-2,000 | 🟡 接近打平 |
| 6-9月 | ¥300-800 | ¥2,000-4,000 | 🟢 盈利 |
| 9-12月 | ¥500-1,000 | ¥5,000-15,000 | 🟢 显著盈利 |

## BMC Lite 与 Lean Canvas 对照

| 维度 | Lean Canvas 侧重 | BMC Lite 补充 |
|------|-----------------|--------------|
| 问题 vs 价值主张 | 从痛点出发 | 从价值创造逻辑出发 |
| 方案 vs 关键活动 | 产品形态 | 运营活动+频率 |
| 渠道 vs 客户关系 | 触达路径 | 关系类型+留存策略 |
| 收入 vs 关键资源/伙伴 | 收入来源 | 资源壁垒+伙伴独立性 |
| 成本 | 固定+可变 | 成本驱动类型+盈亏平衡 |

### 校验结论

BMC Lite 未发现 Lean Canvas 存在重大遗漏。两个关键补充：

1. **关键伙伴独立性原则** — BMC 视角揭示了对 Skill 开发者和平台保持独立性的重要性，这是品牌信任的基础
2. **客户关系分层** — BMC 视角补充了从"自助服务"到"共创"的关系梯度，为运营策略提供框架
