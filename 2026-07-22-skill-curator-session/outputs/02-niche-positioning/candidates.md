# 候选利基与六维评分

> 日期：2026-07-22

---

## 候选 1：🏅「Skill 策展人」— AI Skill 精选策展 IP（主推）

**目标用户**：AI Agent 工具（WorkBuddy/Cursor/Copilot等）的深度用户，面对 SkillHub 8万+ Skill、觅游 4万+ Skill 的信息海洋，不知道哪些值得安装。

**核心痛点**：12万+ Skill 供给，信息过载严重。平台只有货架没有导购。试错成本高（安装、配置、测试），用户需要可信赖的策展人。

**激活的环**：✅ 环1（媒体杠杆+AI自动化）| ✅ 环2（Skill平台爆发+策展空白）| ✅ 环3（跨领域判断力+产品思维）

**时间窗口**：2026Q3，Skill 平台刚过临界规模，策展层完全空白。窗口约 12-18 个月。

**大公司为什么不追**：平台方（腾讯/美团）的 KPI 是做大盘子不是做深精选，生态位天然冲突。工具方聚焦工具层。知识付费方缺乏持续实测能力。

**六维评分**：

| 维度 | 评分 | 说明 |
|------|------|------|
| 痛点强度 | **5** | 12万+ Skill 信息过载，决策成本远高于提示词 |
| 杠杆密度 | **5** | 媒体杠杆极高 + AI 自动化策展 + 未来代码杠杆 |
| 窗口红利 | **5** | 平台过临界点，策展层完全空白 |
| 资源匹配度 | **5** | 跨领域判断力 + 产品思维 + 提示词工程完美匹配 |
| 交付标准化程度 | **5** | 周刊/精选集天然标准化 |
| 现金流潜力 | **4** | 29.9-59.9元/Skill 定价空间，6-12月出正现金流 |

**总分：29/30**

**风险点**：冷启动零流量；平台规则变化风险；AI 交互范式可能演变。

---

## 候选 2：🎓「Skill 架构师」— Skill 开发教程与方法论 IP

**目标用户**：想自己开发 Skill 的产品经理、开发者、设计师。

**核心痛点**：Skill 开发缺少系统性方法论（架构设计、测试、定价、迭代）。

**激活的环**：✅ 环1 | ⚠️ 环2 | ✅ 环3

**六维评分**：

| 维度 | 评分 | 说明 |
|------|------|------|
| 痛点强度 | **4** | 想开发 Skill 的人群在增长 |
| 杠杆密度 | **4** | 媒体杠杆为主 |
| 窗口红利 | **4** | Skill 开发教程品类早期 |
| 资源匹配度 | **4** | 需先积累开发实操经验 |
| 交付标准化程度 | **3** | 教程生产投入较重 |
| 现金流潜力 | **4** | 课程变现路径直接 |

**总分：23/30**

**风险点**：受众比策展窄；需先自建高质量 Skill 建立权威。

---

## 候选 3：📊「Skill 评测局」— Skill 质量评测体系

**目标用户**：Skill 重度用户和开发者，需要客观评测标准。

**核心痛点**：平台评分粗糙，无复现评测方法论。

**激活的环**：✅ 环1 | ⚠️ 环2 | ⚠️ 环3

**六维评分**：

| 维度 | 评分 | 说明 |
|------|------|------|
| 痛点强度 | **3** | 评测有价值但非第一痛点 |
| 杠杆密度 | **4** | 代码+媒体双杠杆 |
| 窗口红利 | **3** | 依赖策展 IP 建立后 |
| 资源匹配度 | **3** | 评测能力待建立 |
| 交付标准化程度 | **4** | 评测框架可标准化 |
| 现金流潜力 | **3** | 变现路径较长 |

**总分：20/30**

**风险点**：独立利基太小，适合作为候选1的产品化延伸。
