# 定位陈述

## 一句话定位

> **「Skill 策展人」**——在 AI Skill 的供给洪流中，做那个帮你筛选的人。

## 完整定位

### 为谁

AI Agent 工具（WorkBuddy、Cursor、Copilot 等）的深度用户——他们已经知道 Skill 的价值，但面对 SkillHub 8万+ Skill、觅游 4万+ Skill 的选择困境，不知道该装哪个、信哪个。

### 解决什么

**核心问题**：信息过载 + 质量焦虑 + 场景匹配困难。

- 信息过载：12万+ Skill，试一个需要安装、配置、测试，成本很高
- 质量焦虑：平台评分体系不成熟，高分不等于好用
- 场景匹配：用户不知道"我的工作场景适合哪个 Skill"

**解决方案**：每周实测精选 AI Skill，提供可信赖的策展——不只是"这个 Skill 做什么"，而是"这个 Skill 在什么场景下好用、有什么坑、和同类比好在哪"。

### 为什么你

创始人具备 Skill 策展最稀缺的能力组合：

- **AI 能力**：能理解 Skill 的技术实现和 AI 能力边界
- **产品思维**：能从用户场景出发判断 Skill 的实际价值
- **前端能力**：能评估 Skill 的技术质量
- **设计审美**：能判断 Skill 产出物的设计水准

这四维交叉视角，让"Skill 策展人"的内容不是泛泛而谈的"好用推荐"，而是经过实测的、多维度的、有判断标准的深度评测。

### 为什么现在

1. Skill 平台刚过临界规模——供给端成熟（12万+ Skill），但策展层完全空白
2. AI Agent 用户群在快速增长——WorkBuddy、Cursor 等工具的 DAU 在持续攀升
3. 先发窗口约 12-18 个月——再等一年，策展内容供给会显著增加
4. 大公司（腾讯/美团）专注于平台规模，不会进入策展层——这是典型的"大公司看得到、做不了"的空间
